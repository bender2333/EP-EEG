free_steps=1024, nudged_steps=12)。为什么会崩：如我们在前序调研中专门强调过的，cadence 默认 nudged_steps=12 是配合 qualified=False（有限步启发式微扰）使用的。一旦开启 qualified=True，cadence 的学习契约强制要求自由相和微扰相都必须收敛到 tolerance=3e-3 才允许更新权重。在包含 88 个双向互通微柱的网络里，施加 $\beta=0.04$ 的逆向推力后，12 个迭代步根本不够水波传回输入端并平息到 $3\times 10^{-3}$ 以下！结果就是每一轮微扰相都判定为未收敛（Refusal），权重永远不更新。   修正指令：只要设 qualified=True，必须同步将 nudged_steps 放宽至 256 或 512（甚至 1024）。   2. 方法论陷阱：跨被试 Euclidean Alignment (EA) 会偷偷混入 $22\times 22$ 空间先验Fable 的建议：在雷区 3 中建议用其余 8 名被试预冲刷，并在跨被试前做 Euclidean Alignment（EA，白化协方差矩阵），称其“不是特征工程”。为什么会破坏你的核心立意：EA 的数学公式是对每个试次的信号 $X \in \mathbb{R}^{22\times T}$ 左乘全导联平均协方差矩阵的逆平方根：$\tilde{X} = \bar{R}^{-1/2} X$。请注意，$\bar{R}^{-1/2}$ 是一个 $22\times 22$ 的稠密空间混合矩阵！一旦左乘了它，第 $c$ 个通道的信号就已经变成了全脑 22 个电极的线性组合。此时你再做“第 $c$ 号浮标一对一垂直注入第 $c$ 号微柱”，C3 微柱接收的早就不是纯粹的 C3 水波，而是混入了 C4 和 Cz 的信号——这会直接摧毁事后脑图谱对账的局部可解释性！修正指令：单被试基准（如先跑 A01）：严禁做跨导联协方差白化（EA），严格只做各导联独立的 Z-score 标准化（用各自导联在 Session T 上的均值和方差归一化），保证 22 个浮标 100% 空间解耦。跨被试预冲刷：只对每个被试的每个导联独立做 Z-score + 分位数尺度对齐（Channel-wise Alignment），绝不左乘跨通道混合矩阵。3. 核心哲学权衡：44 维 $\mu/\beta$ 对数功率 vs. 真正的端到端水波微元Fable 的建议：直接算每个 500 ms 子窗的 $\mu$（8–13 Hz）和 $\beta$（13–30 Hz）两个频带的对数功率（$22\times 2 = 44$ 维）。   工程利弊与折中方案：Fable 提这个方案是为了保住“零空间先验”的同时，用最稳的频域特征快速跑通 Baseline。但人工切好 8–13 Hz 和 13–30 Hz 确实引入了人工频段先验。为了既不牺牲算力（保持 500 ms 子窗），又不违背你的端到端初衷，我们可以在同一个子窗框架下设计可插拔的双轨浮标编码器：   编码器 Track-1（Fable 44 维功率基线）：每导联提取 $[\log P_\mu, \log P_\beta]$。用于第一周工程冒烟测试，确保在 A01 被试上快速打平 Linear LDA，并验证 C3 → 右手 负权重假说。编码器 Track-2（纯时域 66 维 Hjorth 水波微元，零频段切分）：在 4–35 Hz 宽带信号上，对每个 500 ms 子窗直接计算三个纯时域物理积分量（即脑电物理学经典的 Hjorth 时域水波三元组）：水波总能量（Activity）：$E_c = \log(\text{Var}(x_c(t)))$（宽带总起伏方差，无频段假设）；水波平均波速/主频（Mobility）：$M_c = \sqrt{\frac{\text{Var}(dx_c/dt)}{\text{Var}(x_c(t))}}$（一阶导数方差与原信号方差之比，物理意义直接对应水波的均方根角频率 $\bar{\omega}$，无需傅里叶变换！）；水波频谱宽度/复杂度（Complexity）：$C_c = \frac{\text{Mobility}(dx_c/dt)}{\text{Mobility}(x_c(t))}$（刻画水波是单一正弦波还是多频混合波）。这三个量 100% 在时域通过差分与方差算出，既解决了单采样点 $\vert{}x(t)\vert{}$ import numpy as np
import cadence as cd
from cadence.genome import Region, Projection, Genome, develop
from cadence.learning import LearnerConfig, Learner, learning_neuron_model
from cadence.certificate import certificate

def build_certified_alluvial_sandbed(
    n_channels: int = 22,
    in_dim_per_ch: int = 2,   # Track-1 为 2 (μ/β log-power); Track-2 为 3 (Hjorth 水波三元组)
    k_microcolumns: int = 4,  # 每电极正下方垂直锚定 4 个皮层微柱 (22 * 4 = 88)
    n_classes: int = 4,
    init_mesh_scale: float = 0.25,
    seed: int = 0,
):
    regions = (
        [Region(f"in/{c}", size=in_dim_per_ch) for c in range(n_channels)]
        + [Region(f"col/{c}", size=k_microcolumns) for c in range(n_channels)]
        + [Region("motor", size=n_classes)]
    )

    # 自动缩放内部连接强度，确保 100% 拿到压缩映射收敛证书 (certificate)
    scale = init_mesh_scale
    while scale > 0.01:
        # 1. 浮标垂直锚定：单向边界注入 (reciprocal=False)，不挤占微柱的 row_mass 预算
        proj = [
            Projection(f"in/{c}", f"col/{c}", density=1.0, scale=0.5, reciprocal=False)
            for c in range(n_channels)
        ]
        # 2. 湖底全对称冲积沙盘：22 个微柱簇两两全互通 (reciprocal=True, sign=0.0 允许正负抑制演化)
        proj += [
            Projection(f"col/{i}", f"col/{j}", density=1.0, sign=0.0, scale=scale, reciprocal=True)
            for i in range(n_channels)
            for j in range(i + 1, n_channels)
        ]
        # 3. 意图出水口双向耦合：微扰相逆向水波由此回传至全湖
        proj += [
            Projection(f"col/{c}", "motor", density=1.0, sign=0.0, scale=scale, reciprocal=True)
            for c in range(n_channels)
        ]

        conn = develop(Genome(regions, proj), seed=seed)
        brain = cd.NeuralGraph(conn, learning_neuron_model())
        cert = certificate(brain)
        if cert.certified:
            print(f"[Gatekeeper Passed] scale={scale:.3f}, rate={cert.rate:.4f}, mass_limit={cert.mass_limit:.3f}")
            break
        scale *= 0.8
    else:
        raise RuntimeError("无法在当前参数下获得收敛证书，请检查神经元模型配置。")

    # 关键修正：开启 qualified=True 时，nudged_steps 必须给足预算 (256~512)，切勿设为 12！
    cfg = LearnerConfig(
        beta=0.04,
        eta=0.1,               # 适配脑电高噪特性的稳健步长
        centered=True,         # 中心化正负双相微扰对比 (Laborieux et al.)
        qualified=True,        # 严格要求自由相与微扰相均满足残差容限才更新
        tolerance=3e-3,
        free_steps=1024,
        nudged_steps=256,      # 修复 Fable 代码中 nudged_steps=12 导致微扰相无法合格的隐患
        decay=2e-4,            # 内置突触衰减（自动淤平无效河道）
        scale_cap=3.0,
        momentum=0.9,
    )
    learner = Learner(brain, outputs=conn.members("motor"), config=cfg, reciprocal=True)
    return brain, conn, learner

def pack_sensory_drive(conn, X_batch: np.ndarray, n_channels: int = 22, in_dim_per_ch: int = 2) -> np.ndarray:
    """
    将形状为 (batch_size, n_channels, in_dim_per_ch) 的浮标特征打包为 NeuralGraph 所需的全图 drive 向量
    """
    batch_size = X_batch.shape[0]
    drive = np.zeros((batch_size, conn.n), dtype=np.float32)
    for c in range(n_channels):
        idx = conn.members(f"in/{c}")
        drive[:, idx] = np.tanh(X_batch[:, c, :] / 3.0)  # 软限幅保护
    return drive
