# 路线 C2：一次静态平衡内联合输入每导联的包络时间轨迹，导联间共享时域权重

M9/M9b 表明：在当前规模下，无论 EP 还是 BPTT，都没能用梯度训练从原始波形学到超过闭式基线的时序特征。路线 C 回到静态沙盘：ADR-0001 的收敛证书和合格学习都不变，时间维放在输入边界上。

## 决定

- **输入 `envtraj`**：取 Track-2 的 Activity（每导联、每子窗的 log 方差，4–35 Hz 宽带功率包络），按导联排成 11 点时间序列，共 22 × 11 = 242 维，每个试次做**一次**静态平衡。特征在 `ep_eeg` 数据层构造，冻结评估层 `eval/` 不改；按训练集逐维标准化后 `tanh(x/3)`。本 ADR 只在 C2 中取代 ADR-0004 的子窗逐个输入。
- **拓扑**：导联 c 的 11 个时间点只注入导联 c 的 K 个微柱（保留 ADR-0002 的垂直锚定）。
- **导联间共享时域权重**：用 `Learner(tie_groups=...)`，把各导联的"τ → 第 j 个微柱"突触归为同一组 (τ, j)，共 11 × K 个组（K=4 时 44 个输入参数，未共享时为 968 个）。组内初值相同（cadence 文档要求）。这引入的先验是"各皮层位置上 ERD 时程的形状相似"；空间零先验和导联身份都不变。
- **输入尺度**：σ_in 按 fan-in 与 Track-2 匹配（σ_in × 3/11），使期望输入行和与 Track-2 相同。不用 `calibrate`：它对所有突触施加一个全局增益，Track-2 没有用过，用了会引入混杂。初始化时的证书已核实：9 个种子全部通过，row_mass 为 1.08–1.23。
- **更新次数**：每个试次一行，每 epoch 只有 6 次更新；用 1100 epoch，使总更新数与 M6 相同（约 6600 次）。
- **记录**：每 10 epoch 记录一次试次级的 train/val κ（`curve_every=10`），同时报告最佳 epoch 和最后一个 epoch 的 κ；后者是正式结果，前者只作诊断，不用来选参。

## 通过判据（在看到结果前锁定）

`C2-tied` 必须同时满足：
1. 在同输入 shrinkage LDA（`lda_envtraj`，9 人平均 0.295）的基础上，至少 **7/9** 名被试更好；并且
2. 在 9 人平均和逐被试比较上都优于 `C2-untied`（968 个独立输入权重的消融）。

如果最好的结果正好卡在边界（7/9），就扩到 3 个种子再判。

## 已知限制（M9c 分解实验得出）

同输入 LDA 从 Track-2 的 0.389 降到 envtraj 的 0.295，可以拆成三部分（9 人平均）：
- **特征**：去掉 Mobility 和 Complexity，子窗行训练下 0.389 → 0.353；
- **行数**：2112 个子窗行变成 192 个试次行，Track-2 下 0.389 → 0.352；
- **时间分辨**：只用 Activity 时，试次均值 0.309 → 拉开成 11 点时间序列 0.295。

两者都用上时为 0.309。特征损失和行数损失大致相当，都约 0.035–0.045。

## 候选后续（C2b，排队）

如果行数是主要瓶颈：在 11 步上取长度 5、步长 1 的滑动窗口，每个试次得到 7 行；可以同时保留 Hjorth 的全部 3 个通道（同样在 `tie_groups` 下共享，σ_in 缩放为 3/33）。

## 结果（已执行，判据未通过）

2026-10-17 由人接受为历史记录。C2-tied 最后一个 epoch 的 κ 为 0.250，同输入 shrinkage LDA 为 0.295，只有 2/9 名被试更好，判据 1 不通过。tied 与 untied 都是 0.250，判据 2 不通过。最佳 epoch 为 0.301 / 0.309（按验证集挑选，只作诊断）。行和投影在约 6000/6600 次更新中被触发。见 `reports/M9.md` 的 C1、C2 一节和台账 commit 49ff048 / ddc2e30。C2b 未运行。
