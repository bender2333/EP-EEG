# 输入改为子窗特征，采用双轨编码

方案原本在每个采样点注入 [x, Δx, |x|] 共 66 维的瞬时微元，这有两个问题：

- **过零闪烁**：|x| 以 2 倍频在 0 和振幅之间闪烁，过零点处平衡点会抖动。
- **算力**：按 250 Hz 逐点求解，每个 epoch 约需 21.6 万次平衡求解，用 NumPy 跑一个 epoch 要以小时计。

改为：截取提示后 0.5–3.5 s 的数据，以 500 ms 窗长、250 ms 步长切成 11 个子窗，每个 epoch 共 288×11 = 3168 个样本。每个子窗为每个导联计算一组特征，分两轨：

- **Track-1**（44 维）：每导联 μ（8–13 Hz）和 β（13–30 Hz）两个频带的对数功率。只用于工程冒烟测试，以及与同输入的 LDA 对齐。
- **Track-2**（66 维）：每导联的 Hjorth 三元组（Activity = log Var、Mobility、Complexity）。只用时域方差和差分计算，不切频带。

组 1–3 比较的主结论只用 Track-2。"零先验"的声明范围相应收窄为：**无空间先验、无频带切分**。4–35 Hz 的物理清洗和 Hjorth 统计量本身，仍属保留下来的人工选择。

训练时，每个子窗使用所属试次的标签，采用固定 β，各子窗等权微扰。特征先经 tanh(x/3) 软压缩再注入，因为 cadence 本身不压缩输入。

## Considered Options

- **正交能量对 √(x² + (Δx/ω₀)²)**：只在单一频率 ω₀ 附近恒定，宽带信号下仍有纹波。
- **用网络自由相的置信度门控 β**：训练早期网络对错误类别也会很自信，门控会放大错误的更新，形成正反馈。如果以后要做门控，作为消融，并且只用试次级的 ERD 能量，不用网络自己的输出。

## Consequences

- 一个试次的判决如何由 11 个子窗聚合得出，尚未决定。
