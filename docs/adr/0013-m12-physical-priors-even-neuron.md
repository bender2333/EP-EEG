# M12：零解剖先验 + 四条物理先验；带光滑偶分量的神经元模型

M0–M11 的「零结构先验」把三件事绑在了一起：不规定导联之间怎么连（解剖），不用 EA（ADR-0005），输入一对一锚定在导联下方（ADR-0002）。M11 B 显示证书约束下湖的上限等于输入的上限；M9c 推论指出对称 tanh 是奇函数，表示不了功率与协方差这类偶函数量。M12 指令（人，2026-10-19）把「零结构先验」改为「零**解剖**先验 + 显式的**物理**先验」，并要求神经元带光滑偶分量。本 ADR 逐条写下这些先验和神经元模型。

## 判断标准

一条先验若对任何皮层位置、任何被试都同样成立，它是物理的；若它编码了「哪里连哪里」，它是解剖的。M12 只允许物理先验。

## 决定

### 零解剖先验

- 不规定任何导联之间的连接，不按 10-20 坐标初始化，不按脑区分组。
- 入口全混合：每个入口神经元可读全部输入分量，随机初始化。零先验 = 随机初始化，不等于零混合。
- 这一条在 M12 中**取代 ADR-0002 的垂直锚定**（M11 B：垂直注入不带来任何上限收益）。

### 物理先验（只有这四条）

1. **时间平移不变**：入口权重跨时间位置共享（`Learner(tie_groups=...)`，组 = (空间滤波 k, 输入分量 c)，跨 T 个时间位置）。跨数据集共享入口权重时须先经 S4 的通道映射。
2. **功率是偶函数**：神经元带光滑偶分量（见下）。
3. **信号平稳性**：Euclidean Alignment。R̄ 只用训练部分估计，OAS 收缩后开 −1/2 次方；白化矩阵随回执保存；用目标被试无标签数据时标 `transductive=true`。EA 之后的「导联」是白化分量，不再称作电极；地形图经 R̄^{1/2} 映射回电极空间再画。这一条在 M12 中**取代 ADR-0005 的「不用 EA」**；ADR-0005 的 EOG 回归、4–35 Hz 带通、按训练统计量 z-score 保留。
4. **带通**：4–35 Hz 带通，或 4 带滤波器组（S3 备选）；之后重采样到 80 Hz（≥ 2.2 × 带上限）。离线阶段（S2–S4）用零相移滤波；S5 的在线流式解码不能用非因果滤波，改用因果滤波器组，并在 S5 预注册里给出离线与在线滤波差异的对照（M11 C 用的也是因果滤波）。

### 神经元模型

ρ(v) = a·tanh(v/2) + b·tanh²(v/2)，a > 0，b 实数，按群体配置。

- ρ(0) = 0，静息发放为 0；C^∞ 光滑，0 处没有折点（M11 D1：leak = 0.1 的折点在有限 β 下把 cos(EP, IFT) 拉到 0.54–0.92，M12 一律禁止折点）。
- a = 1、b = 0 即现行 `learning_neuron_model(leak=1.0)` 的 tanh(v/2)。
- 偶分量 b·tanh²(v/2) 在小 v 时 ≈ b·v²/4，使一个神经元可以表示 (w·x)² 这类二次量，从而表示加窗功率与协方差。
- 导数 ρ′(v) = ½(1 − t²)(a + 2bt)，t = tanh(v/2)。|b| > a/2 时 ρ 非单调，ρ′ 在 t = −a/(2b) 为 0。
- **Lipschitz 常数**：L(a, b) = ½ max{ |(1 − t²)(a + 2bt)| : t ∈ {t+, t−} ∩ (−1, 1) }，t± = (−a ± √(a² + 12b²))/(6b)；b = 0 时 L = a/2。只依赖 |b|。例：L(1, 0.25) = 0.528，L(1, 0.5) = 16/27，L(1, 1) = 0.758。数值实现用稳定形式 t+ = 2b/(a + √(a² + 12b²))。
- **EP 的适用性**：记 F(v) = −v + Wρ(v) + c，Φ(v) = ½ρᵀWρ + cᵀρ − Σ_i ∫₀^{v_i} u ρ′(u) du，则 ∂Φ/∂v_i = ρ′(v_i)·F_i，平衡点是 Φ 的驻点；EP 的推导只需要平衡点关于 β 可微（证书保证 I − W·diag(ρ′) 可逆），不需要 ρ 单调。注意：在 ρ′_i = 0 处 ∇²Φ 奇异，Φ 的驻点也比 F 的零点多，所以论证只用「F 的不动点 + 隐函数定理」表述，不说平衡点是能量极小。这只是论证，由 S0 的 D1 复跑在单调和非单调两种 (a, b) 上数值确认。

### 输入群体与证书

- 输入神经元**不经激活**：发放等于钳制值（常数驱动），不计入行质量，幅度自由（避免 M9c 的入口饱和）。
- 证书一律用 ADR-0012 的级联版，并按群体 Lipschitz 常数加权：ρ̃_free = max_{i∈free} Σ_{j∈free} |W_ij|·L_j < 1，q_f = 1 − dt(1 − ρ̃_free)。行质量投影只作用于 free→free 边。这一条把 **ADR-0012 的适用范围从 M9c 扩展到 M12 的全部 arm**。

## 参数量

S3 架构（入口 K = 8 个空间滤波 × 80 个时间位置，跨时间绑定；K 个汇聚神经元；两层内部全互惠；4 个 motor）的参数量在 S3 预注册时写入本节，ADR 定稿前补齐。

## Considered Options

- **保留 ADR-0005（不用 EA）**：M11 B 与 G2 显示 N = 192 时训练湖与随机湖 Δ ≈ 0，样本量是前置条件；EA 跨被试合并是唯一的扩量手段。
- **保留 ADR-0002（垂直锚定）**：M11 B 显示无上限收益，且锚定本身就是解剖先验。
- **|v|**：0 处有折点，排除。**ReLU²**：C¹ 而非 C²（ρ″ 在 0 处不连续），排除。softplus 类不是偶分量，不在比较之列。
- **纯偶函数神经元（a = 0）**：失去符号信息，且 L 较小；a、b 留作按群体配置，由 S1 选定比例。
- **非对称结构、去绑定消融**：M11 D1、G1 已证明 EP 对比量只估计成对共享权重的梯度，不作为 arm。
