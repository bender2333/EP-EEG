# 时序阶段（M9）：用路径 EP（PartitionedTemporalPatchNet）直接从波形学习时空特征

M0–M6 的静态子窗沙盘按 ADR-0001/0004 只做「手工 Hjorth 特征 → 静态平衡」分类：时间信息只在人工特征里，EP 实际只训练出一个接近随机特征池的读出（M2：只训读出 0.269 vs 全训 0.287）。这回答不了项目的本意——**让 EP 动力系统自己从时空信号中学特征**。

M7/M8 试图在带证书的 `NeuralGraph` 上用 warm 链恢复时间维，但 ADR-0001 已证明：证书（rate<1）是压缩映射，给定驱动下平衡态唯一，warm 启动在容限内被抹掉，网络没有跨步记忆。M7 的机会水平结果（κ=−0.008，内部状态 std≈0.003）与此一致。warm 链路线不再继续。

ADR-0001 当时把时序版本指向 `TemporalPatchNet`：对整段路径联合求解自由相与 ±β 相。本 ADR 在一个**新阶段 M9** 内采用它，取代该阶段内的 ADR-0001（静态平衡）和 ADR-0004（子窗特征输入）；M0–M6 的结论与 ADR 不受影响。

## 决定

- **模型**：`cadence.experimental.PartitionedTemporalPatchNet`（cadence `6499e56`）。
  `h[t] = A·tanh(h[t-1]) + B·u[t]`，`y[t] = C·tanh(h[t])`；路径能量上做中心化 ±β EP，带 `contrast_asymmetry` 检查与 β 自动折半。
- **拓扑（保留 ADR-0002 的锚定）**：每导联 k 个微柱，隐藏宽度 H=22k。
  - 掩码 B：导联 c 只注入它下方的 k 个微柱（垂直锚定，保留头皮坐标）。
  - 掩码 A：微柱之间全连通（无空间先验）；A 是网络自己学的时空滤波器。
  - 掩码 C：微柱→4 个出水口全连通。
- **输入**：冻结评估层的同一段信号（EOG 回归 → 4–35 Hz → 逐导联 Z-score，只用 T run 0–3 拟合；提示后 0.5–3.5 s），**不算 Hjorth**，250→125 Hz 抽取（信号已低于 35 Hz），`tanh(x/3)` 压缩。每步 drive = 22 维原始波形。
- **目标**：二次损失（TemporalPatchNet 唯一的损失），目标为该试次类别的 one-hot，施加在路径的每个时间步上。
- **训练**：每 epoch 从每个训练试次的 3 s 段中随机截取一段 crop（默认 1 s=125 步），初始边界为零态。
- **判决**：验证试次跑整段 375 步的因果自由路径（无需迭代求解），对 t ≥ crop 长度之后的输出取平均后 argmax。合格率分母 = 全部被尝试的学习步（`observe` 返回 `updated=False` 记为拒学）。
- **切分与留出**：沿用冻结协议（T run 0–3 训练 / run 4–5 验证）；M9 不读取 E。

## 与原研究问题的差异（必须如实报告）

- **不再是「全对称介质」**：A 不要求对称；EP 作用在路径能量（预测编码式）上，而不是对称 Hopfield 能量。
- **只保证局部极小**：cadence 对路径解只证明返回的是局部极小（Schur 主元为正），不证明唯一平衡；「证书」被每相收敛检查 + contrast_asymmetry 取代。
- **二次损失**，不是交叉熵。
- **成本**：NumPy 实现，块 Hessian 求解成本约 O(batch·T·H³)。实测（4 线程）一次 observe：H=44/T=125/batch 16 约 4 s；H=88/T=375 约 60 s。

## Considered Options

- **NeuralGraph + warm 链（M7/M8）**：被 ADR-0001 证明无记忆；已在 M7 实测为机会水平。放弃。
- **NeuralGraph 有限步松弛（`qualified=False`）**：产生记忆，但训练的是截断 RNN，不再是 EP；只作消融。
- **整段 3 s（T=375）直接训练**：H=88 时每 epoch 约 12 分钟/被试；先在 1 s crop、H=44 上找到信号，再放大。

## Consequences

- 需要人接受本 ADR 后，M9 结果才能进入主结论；在此之前 M9 只是探索性试点。
- 跨被试预训练与读取 E 仍由人决定。
- 对照：同一 T 切分上的 Track-2 LDA（M0）作为参照；同模型打乱标签作为机会对照。
