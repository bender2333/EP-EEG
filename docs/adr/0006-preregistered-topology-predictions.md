# 拓扑结论只检验预注册的可证伪预测

方案中"训练后看热力图找河道"的做法是不可证伪的，因此改为在训练前写下预测。解读任何拓扑之前，以下两项前提必须先成立：

1. 在同一输入上，沙盘的解码性能不低于线性 LDA。否则"冲刷出功能河道"的叙事没有立足点。
2. 预测在多个种子上稳定，并且在对照条件下不出现。

**被预测的量是输入敏感度**：在自由平衡点处对某导联的功率类特征（Track-1 的 log P、Track-2 的 Activity）施加微小扰动，出水口活动随之变化的符号，在验证集试次上取平均。

讨论 02、03 原本预测的是"C3 微柱 → 右手出水口的权重为负"。但输入到微柱这一段的权重符号是随机初始化的，所以单看微柱到出水口这一段的权重符号，无法辨识方向。直接连接的两段乘积 Σ_k W[输入→微柱_k]·W[微柱_k→出水口] 只作为分解报告，不作为判据。

| 想象类别 | 预测 |
| --- | --- |
| 右手 | C3 功率 → 右手出水口的敏感度 < 0（对侧 ERD：功率下降） |
| 左手 | C4 功率 → 左手出水口的敏感度 < 0 |
| 双脚 | Cz 功率 → 双脚出水口的敏感度 < 0；C3/C4 → 双脚可能 > 0（周边 ERS，属弱预测） |
| 舌头 | 不做预注册预测，属探索性 |

对照组如下：

- 同输入 LDA
- 打乱标签训练
- 未训练的初始化
- 保持对称的拓扑打乱

`cd.shuffled` 只置换突触的终点，不保留反向配对，会破坏对称性，还可能产生重复的突触对，导致 `Learner(reciprocal=True)` 报错。所以保持对称的打乱要在本仓库实现：成对打乱后用 `Connectome.from_synapses` 合并。

预注册以外的发现（例如额-顶斜向的长程连接）一律标为探索性。

来源：`docs/discussions/` 02 雷区 8、03 第一节与第四节 Step 5。敏感度的定义和对称打乱的要求是整理时补充的。
