# 预处理只做逐导联的变换，不用 Euclidean Alignment

Euclidean Alignment（EA）等跨导联白化，是 BCI 跨被试、跨会话时常用的提分手段。但 EA 要左乘一个 22×22 的稠密矩阵 R̄^(−1/2)，做完之后每个导联的信号都成了全部导联的线性组合，C3 微柱收到的已经不是 C3 的信号，[ADR-0002](0002-vertically-anchored-mesh.md) 的一对一锚定和事后拓扑对账都会失去意义。

因此预处理只做不混合 EEG 导联的物理清洗，依次为：

1. **EOG 回归**：从每个 EEG 导联中减去 3 导 EOG 的线性组合。
2. **4–35 Hz 零相移带通**。
3. **逐导联 Z-score**：统计量只取自本次训练所用的数据。

跨被试对齐如有需要，只做逐导联的尺度对齐。

## Considered Options

- **EA**：理由见上。按同一原则，CAR、表面拉普拉斯、CSP 等跨导联空间变换也一并排除。
- **0.5–40 Hz 带通（方案原版）**：0.5–4 Hz 的慢波和眼电，幅值是 μ/β 节律的 5–10 倍，会淹没运动想象信号；而 30–40 Hz 的肌电毛刺会主导差分特征。

## Consequences

- EOG 回归需要眼动标定段，或者至少需要训练数据中的 EOG 导联。M0 要确认 MOABB 提供的数据里是否包含标定段。
