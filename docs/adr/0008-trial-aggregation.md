# 试次聚合与「正常脑电段」分母（M0 冻结）

AGENTS.md 将两项延后到 M1。为避免在看验证指标后再改评分，本稿在 M0 实现评估层时一并冻结：

1. **试次判决**：合格子窗的出水口活动（或类概率）逐类取平均，argmax 为预测。无合格子窗时，用训练集多数类（并列取最低类索引）作为四分类预测，并记拒绝。主要 κ 始终覆盖全部预定试次。
2. **「正常脑电段」分母**：所有预定被尝试的子窗/相位（源 artifact 规则确定后）；不因模型失败或预测错误事后缩小。当前 artifact 处理为 `ignore`（保留全部标签试次）；源 MAT 中 3 段无事件记录是否为 EOG 标定材料未由数据说明确认，故 EOG 回归只用 T run 0–3。
3. **覆盖率阈值**：报告「至少 8/11 子窗合格」的试次覆盖率；该阈值不因验证表现调整。

实现见 `eval/scoring.py`。
