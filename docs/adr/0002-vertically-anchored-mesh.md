# 沙盘采用垂直锚定、全对称互通的拓扑

方案中的 128 个隐藏神经元各向同性，排列置换后不变，因此没有头皮坐标：组 2 的距离初始化和事后的拓扑对账都无从谈起。而且 66→128 的全连接加上内部全连接，共约 1.6 万个参数，对每名被试 288 个试次来说严重过参数化。

改为以下结构：

- **微柱**：每个导联下方放 k 个神经元（k=4 时共 88 个）。
- **输入**：每个导联的特征只单向注入它下方的微柱。
- **沙盘内部**：微柱之间全对称、全互通。
- **出水口**：微柱与出水口双向耦合。

这样每个沙盘神经元都继承所属导联的头皮坐标，注入参数从约 8.4k 降到 22×d×k；导联之间仍可以冲刷出任意方向的河道，不引入空间先验。

## Consequences

- **输入投射用单向**（`reciprocal=False`）：单向输入在能量函数中属于驱动项，输入神经元是源节点，符合 EP 对固定输入的假设（可以用 `ep_structure(fixed_inputs=...)` 检查）。如果用双向投射，输入神经元会接收反馈，变成自由变量。讨论 02 的示例代码用了双向投射；讨论 03 给出的单向理由（"不挤占 row_mass"）不成立，因为 row_mass 计入所有入射突触，包括单向投射。
- **参数量仍偏大**：约 4.1k（264 + 88×87/2），与 288 个试次之比约 14:1。正则化依靠 `decay`；是否做跨被试预训练尚未决定。
- **组 2 的定位**：组 2 用导联间头皮距离做高斯初始化，属于空间先验，作为消融组，不进入"零先验"的主结论。
- **拓扑对账的尺度**：在 22×22（按导联聚合的微柱之间）和 22×出水口两个尺度上进行（见 [ADR-0006](0006-preregistered-topology-predictions.md)）。
