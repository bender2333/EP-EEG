## 1. 科学问题与可声明的结论

主问题是：在固定数据、特征、求解条件和搜索预算下，**无导联间距离或脑区屏蔽先验的对称循环沙盘**，能否达到有竞争力的四分类性能，并产生跨被试、跨种子稳定且与对照不同的输入敏感度？

这里的“无空间先验”只指沙盘内部不使用导联间距离初始化、不设置人工脑区隔墙。逐导联锚定、4–35 Hz 清洗、Hjorth 统计量、四分类标签、对称连接和收敛约束本身都是设计选择。报告不得使用“完全零先验”或“模型直接发现了真实脑连接”。

M1–M4 是**静态子窗模型**：每个子窗独立求平衡，时间信息只存在于该子窗的统计特征中。Track-1/2 都不含跨导联相位或传播时延，因此这几个阶段不能证明脑电行波、神经时序记忆或真实脑区因果连接。日后若研究序列动力学，应另立阶段、模型和评估协议。

预设问题分为三层，不能互相替代：

1. **工程可行性**：自由相和微扰相能否稳定求解，局部 EP 更新是否具有可信的梯度方向，训练成本是否可接受？
2. **解码效果**：组 1 与同 Track-2 输入的 LDA、参数量相近的 MLP、人工脑区组和传统基线相比，在被试级 κ、覆盖率和成本上表现如何？
3. **模型机制**：训练微柱间连接是否比固定随机沙盘有用，预注册输入敏感度是否稳定且在阴性对照下消失？

失败也是有效结论。若组 1 未超过 LDA、梯度核验失败或拓扑不稳定，应如实报告，不通过修改评分、事后筛选被试或无限增加候选来挽救假设。

## 2. 数据、切分和留出边界

数据为 MOABB `BNCI2014_001`，即 BCI Competition IV-2a。9 名被试各有 T、E 两个会话；每个会话有 6 个任务 run，每个 run 48 个试次，四类各 12 个；采样率 250 Hz，含 22 导 EEG 和 3 导 EOG。每名被试独立训练，不混合目标被试的 E。

| 数据 | 用途 | 每被试独立试次数 |
| --- | --- | ---: |
| T run 0–3 | 训练、EOG 系数和标准化统计量拟合 | 192 |
| T run 4–5 | 验证、选参、阶段内 keep/discard | 96 |
| E 六个任务 run | 最终留出集，仅在冻结后读取 | 288 |

当前讨论中“约 4.1k 参数对 288 试次”的说法低估了开发阶段过拟合风险：按本切分，训练只有 **192 个独立试次**；每试次 11 个子窗共享标签，并不是 11 倍独立证据。输出连接和偏置也应计入模型容量，最终参数量由实际 Connectome 计算并写入 receipt。

训练与验证期间，数据适配层必须在打开文件前就限定为 `AxxT.mat`。已核对的 MOABB 1.7.2 通用 `BNCI2014_001.get_data(sessions=...)` 会先加载 T/E 再过滤，不能用作研究循环的 T-only 入口。任何普通 runner 不得有隐式 E 路径。T 中的三段无任务事件记录是否为可用的 EOG 标定材料，目前只能列为待核对事实，不能凭“无事件”直接认定。

**本稿建议的留出策略**：M0–M4 所有候选、对照、超参数、试次评分和拓扑判据只在 T 上形成；最终冻结每组一个预定候选及训练日程，随后对 E 进行一次共同评估。最终模型可从头用完整 T 的 288 个试次重训，但 epoch 数、种子集合、预处理和所有超参数必须先由 T 验证确定，E 不参与停止或选择。若人决定保留旧协议的逐阶段 E 评估，所有后续方法都已受 E 间接影响，必须把 E 称为开发性阶段证据，并另找独立资料作最终确认。此决策须在首次查看 E 前作出。

## 3. 冻结评估层和输入编码

`eval/` 是唯一的数据加载、切分、试次聚合和评分入口，在 M0 建立并冻结。之后研究循环只调用它；修改它必须开启新阶段并说明原因。所有 arm 使用同一试次集合、类别顺序、源 artifact 处理、随机种子清单和成本口径。

预处理按以下顺序执行，每一步需要记录实现、参数与训练统计量来源：

1. 用 T 训练材料拟合 EOG→逐导联 EEG 的线性回归并应用；禁止混合 EEG 导联。若三段无事件记录经源资料确认是眼动标定材料，可只用 T 中的这些材料；否则仅用 T run 0–3。不能用验证或 E 的信号拟合回归系数。
2. 按 run 分别做 4–35 Hz 零相移带通。它服务于离线评估，不能由此声称在线实时性。
3. 用 T run 0–3 的统计量逐 EEG 导联做 Z-score；不能做 Euclidean Alignment、CAR、表面拉普拉斯或其他混合导联的主线变换。FBCSP 是单独的传统基线，不属于主线输入。
4. 取 cue 后 0.5–3.5 s（从试次起点计为 2.5–5.5 s）；500 ms 窗长、250 ms 步长，共 11 个子窗。
5. 每个子窗计算导联特征。若需要按特征维度再次标准化，参数也只能从 T run 0–3 拟合，并在 M0 冻结；之后再做 `tanh(x/3)` 软压缩。需在 M0 核实 cadence 输入神经元本身的非线性，不把“软压缩后的 drive”误写成神经元实际发布活动。

| 轨道 | 每导联特征 | 总维度 | 用途 |
| --- | --- | ---: | --- |
| Track-1 | μ（8–13 Hz）与 β（13–30 Hz）对数功率 | 44 | 工程冒烟、传统特征对齐及同输入 LDA |
| Track-2 | Hjorth Activity=`log Var`、Mobility、Complexity | 66 | 组 1–3 和主结论 |

Track-2 没有预设 μ/β 分带，但经 4–35 Hz 滤波，其统计量也保留频谱信息；不得称为“无频率先验”。原计划中的逐采样点 `[x, Δx, |x|]`、跨子窗状态和正交能量对均不进入主线。

源 artifact 标记必须在 M0 看验证结果前确定统一规则，记录每组保留/排除试次数。按预测、收敛状况或拓扑结果事后删试次属于协议违规。建议另做“全部标签试次”和“按源标记排除”的固定敏感性分析。

## 4. 平衡态网络与学习原理

主线直接使用 cadence-net 0.83.0、commit `6499e56` 的 `Genome`/`Connectome`、`NeuralGraph`、`Learner`；不使用 `Brain.compose`。cadence 源码只读。固定输入驱动下，沙盘求自由平衡 `s⁰`，输出端施加中心化 `+β`、`−β` 微扰，得到 `s⁺`、`s⁻`；成对互惠突触按两端活动的对比更新。该更新的梯度解释要求有效自由变量连接对称、输入固定、三相在兼容的平衡分支上。局部突触对比并不意味着整个算法没有全局相位控制、标签或收敛检查。

主结构遵循 ADR-0001 至 ADR-0003：

- 每个导联下方 `k=4` 个微柱神经元，共 88 个；输入区域按 Track 维度建立，只单向投射到所属微柱，不让输入神经元成为自由变量。
- 沙盘内部为无脑区屏蔽的互惠连接；微柱与四个出水口神经元也互惠。四分类只有一个动作槽。
- `Region` 名称不得含 `/`；例如 `in_00`、`col_00`、`motor`。drive 宽度必须是 `(batch, conn.n)`。
- 出水口的侧抑制不是低层接口默认值。M1 主线暂不添加；若研究侧抑制，须对所有结构组一致施加，并作为单独配置记录。
- 特征压缩、完整 drive 组装、保存加载、证书门禁、可选 L1/剪枝和对称打乱，都由本仓库适配层负责；不能把 cadence 的乘性 `decay`、建图期 `min_count` 或单突触 `scale_cap` 当成在线 L1 或行质量约束。

默认 `learning_neuron_model()` 的 `dt=0.5`、激活斜率上界 `L=0.5`。其正、负电位响应斜率在零点不连续；因此平滑分支下的中心化误差阶数不能无条件套用。M1 必须检查实际有效互惠权重的对称性、自由相证书、微扰相合格性，并在小型可控图上把 EP 更新与有限差分或隐式梯度的方向作比较。

自由相 `certificate(graph).certified` 要求 rate<1 且无 adaptation；证书按最大入射有效权重绝对行和计算，单向输入也计入。证书仅覆盖自由相，微扰相需另核查 nudge 带来的收敛余量和实际残差。初始化与**每个 epoch 结束**都检查。证书失效时停止并记失败，不能在同一候选中静默提高 decay 或重归一化。`qualified=True` 时正负微扰预算应与自由相预算相当，不能沿用旧示例的 `12` 或 `256/1024`。

下表只是 M1 的**待验证起点**，不是已经证明合适的超参数；执行时 `LearnerConfig` 每个字段都显式给出：

| 参数 | 候选起点 | 必须核查 |
| --- | --- | --- |
| `beta` | 0.04 | 微扰分支、有限 β 误差、微扰相收敛余量 |
| `eta`、`eta_bias` | 0.10、0.01 | 更新幅度与输出饱和 |
| `free_steps`、`nudged_steps` | 1024、1024 | 预算、合格率和实际耗时 |
| `tolerance` | 3e-3 | 残差与更新方向误差；不能只看是否达到阈值 |
| `centered`、`qualified` | `True`、`True` | 两个微扰相都必须合格 |
| `nudge`、`temperature` | `cross_entropy`、0.2 | 四分类目标和收敛条件 |
| `decay`、`momentum`、`normalize` | 0、0、0 | 后续各自作为单变量实验 |
| `scale_cap`、`damping` | 3、3 | 单突触裁剪不能替代证书 |

`TemporalPatchNet` 自带的 `contrast_asymmetry` 和自动 β 折半不属于本静态主线。若适配层实现类似诊断，必须先验证其数学与 API 契约，再作为新实验变量登记。

## 5. 结构组、基线与因果识别

组 1–3 的主对比只用 Track-2，统一 88 个沙盘神经元、输入/输出定义、epoch 日程、学习规则、求解门槛、种子集合和试次评分。

| 组 | 结构变量 | 能回答的问题 | 解释限制 |
| --- | --- | --- | --- |
| 1：均匀沙盘 | 不使用导联距离或脑区屏蔽，互惠全连通 | 无导联间空间先验的性能上限 | 边数和容量可能高于稀疏组 |
| 2：距离软先验 | 仅初始化按头皮距离缩放，保持与组 1 相同边集 | 距离初始化是否有益 | 本组显式含空间先验 |
| 3：五脑区结构 | 预注册五脑区映射与互惠边掩码 | 人工结构限制对性能的影响 | 与全连通组的边数不同，不能单独归因于“生理先验好坏” |
| 4：传统基线 | FBCSP、EEGNet、同输入 LDA | 实用解码参照 | FBCSP/EEGNet 输入与归纳偏置不同 |

组 3 的导联归区、允许/禁止边、初始化幅度、边数与行质量，要在 M2 前由新 ADR 冻结。原方案组 3 的 Trace 记忆环与“只改结构”冲突，本稿建议移出主对照，作为单独时序消融。即使组 1 胜过组 3，也不能单凭此判断人工脑区先验有害，因为全连通与硬屏蔽之间还差容量、度分布和优化难度。

为区分这些解释，M2 增加预先声明的辅助对照：

- **同 Track-2 输入、参数量相近的 MLP**：检查收益是否只是非线性/容量，而非 EP 或循环平衡。
- **同一沙盘但固定随机微柱间权重、只训练读出**：检查学到的内部连接是否必要。
- **与组 3 边数和度分布匹配的随机互惠稀疏图**：检查五脑区边的具体布置是否优于一般稀疏结构。
- **打乱标签、未训练初始化和 EOG-only 输入**：分别检查泄漏、训练贡献和眼动/提示线索混杂。

在一个完全连通的组 1 图上，简单“交换边端点”不能构成有意义的邻接结构打乱。若要检验**已学习权重的排列**是否重要，应在无序互惠边对之间成对置换权重，同时固定输入/输出锚定、边数和权重分布；若要检验**稀疏结构**，则用组 3 的等度随机掩码并从头训练。两种对照回答不同问题，不得统称为“拓扑打乱”。cadence 的 `cd.shuffled` 不保留反向配对，不用于本主线。

## 6. 试次判决、拒绝与成本

11 个子窗各自从固定初始状态求自由平衡；每个子窗先得到四个出水口活动。**本稿建议**：合格子窗的输出活动逐类取平均，最大者为试次预测；若一个试次没有合格子窗，则按预先固定的训练集多数类（类别相同数时按固定类别顺序）给出四分类预测，同时记为拒绝。这样主要 κ 始终覆盖所有预定试次，不能只在容易求解的试次上报分数。

同时报告子窗合格率、至少 8/11 子窗合格的试次覆盖率、完全拒绝试次数、被拒子窗数、自由相和正/负微扰相的合格率与拒学数。“正常脑电段”的分母在源 artifact 规则确定后就是**所有预定被尝试的子窗/相位**，不因模型失败或预测错误而事后缩小。8/11 是待人确认的预注册覆盖阈值，不能用验证表现调整。

残差小只表示数值求解达到要求，不表示分类正确。每个 accuracy 或 κ 都必须同时列出覆盖率、拒行数和合格率。成本包含自由相、正微扰相、负微扰相和被拒求解；基线也要用同一计时边界报告数据处理、训练、选择与推理成本。若各方法无法完全匹配计时口径，拆分报告，不制造一个不可比的“总成本”。

## 7. 搜索、统计和最终检验

阶段内搜索目标是 9 名被试的平均验证 κ，辅助看覆盖率、求解合格率、拒学率、成本和被试间差异。任何搜索都只使用 T run 4–5。快速档只作工程筛选；完整档至少 9 名被试 × 3 个种子。候选数量、变量范围和每组预算在看到结果前登记；`results.tsv` 保留所有 keep、discard 和 crash。反复查看 96 个验证试次同样会过拟合，所以自动化不能无限提出新候选。

建议的最终主要性能比较为组 1 与组 3、组 1 与同输入容量相近 MLP 的被试级 κ 差；前者检验**性能差异**，不单独证明脑区先验的因果效果。组 3 与等度随机稀疏图是解释脑区布置的辅助比较。同输入 LDA 是 M1 可行性参照，FBCSP/EEGNet 是实用基线。主要比较、最小有意义差值和多重比较处理须在 M2 前冻结。

每名被试先汇总预设种子，再按被试配对；报告 9 名被试的原始值、配对差、区间估计、效应量和 Wilcoxon 符号秩结果。不能把 9×3 个训练结果当成 27 个独立被试。9 名被试的统计功效有限；结论须体现区间宽度，不能只写显著/不显著。原“提升超过种子标准差即 keep”的规则只能作为筛选提示，不是统计确认规则。

留出评估之前，应冻结：所有候选代码与配置、源数据和依赖哈希、训练轮数、种子、artifact 规则、聚合/拒绝规则、主要比较、敏感度预测和统计脚本。最终重训只用 T，会话 E 每个冻结候选只评价一次。若看过 E 再修改方法，旧 E 不再是新方法的独立确认资料。

## 8. 预注册输入敏感度和混杂控制

按 ADR-0006，只有组 1 验证性能不低于同输入 LDA、多个种子稳定、打乱标签接近机会且对照条件不出现相同模式时，才检验预注册预测。主量为**自由平衡点处某导联功率类特征的微小扰动引起的目标出水口活动变化**，而非某一段权重的符号。右手预测 C3→右手输出为负，左手预测 C4→左手输出为负，双脚预测 Cz→双脚输出为负；C3/C4→双脚为弱预测，舌头只作探索。

M3 前预注册：扰动作用在训练标准化后的哪个特征、幅度及稳定性范围、按目标类试次汇总的方式、合格求解的处理和跨被试/种子的判据。建议以目标出水口活动为 ADR 主判据，同时报告与其他类的输出差作为稳健性分析。ERD 是类别相关的观测差异，不逻辑必然推出分类器导数符号；预测不成立时如实判定，不改写判据。

控制包括同输入 LDA、打乱标签、未训练图、互惠权重排列或等度随机稀疏图。另做 EOG-only、不同任务子窗和预先固定的感觉运动导联消融，排查箭头提示诱发的视觉/眼动信息。即使模型敏感度方向符合预期，也只表明模型功能响应；体积传导、共同参考、隐藏微柱置换等因素使它不能直接作为生物连接证据。额顶等预注册外发现一律标“探索性”。

## 9. 阶段路线和验收

| 阶段 | 主要工作 | 阶段门证据 |
| --- | --- | --- |
| M0 数据与基线 | 确认 T-only 加载、EOG 材料、artifact、预处理、试次评分；冻结 `eval/`；完成 LDA、FBCSP、EEGNet、打乱标签和同输入 MLP 基线 | 9 被试 × ≥3 种子结果、机会水平控制、实测时间预算、评估层版本和数据哈希；不以 E 作为选参依据 |
| M1 EP 可行性 | 小图梯度方向核验；A01 工程冒烟后扩到 9 被试；证书与正/负相合格率监控 | 证书逐 epoch 通过、目标联合合格率 ≥98%、覆盖率和拒学完整；验证 κ 与 LDA 比较，允许负结果结项 |
| M2 结构比较 | 组 1–3 与匹配对照，同 Track-2、同搜索协议；组 3 先有被接受 ADR | 被试级比较、容量/度/行质量、成本和预算差异完整；无法匹配时只作描述性结论 |
| M3 输入敏感度 | 冻结扰动与判据，检验预注册 C3/C4/Cz 预测及阴性对照 | 每项为成立、不成立或证据不足，多种子/被试结果与对照齐全 |
| M4 坏导联鲁棒性 | 所有组使用相同、预先固定的 2–4 导联断导集合 | κ、覆盖率、拒行率随断导数的退化曲线；断导位置与处理阶段记录 |
| 最终 E 阶段门 | M0–M4 的方法与分析全部冻结，按预定日程重训并一次性评估 E | 每名被试的性能、主比较、输入敏感度和鲁棒性结果、完整 receipt；不得回调方法 |
| M5 出水口扩展 | 冻结 M2 组 1 沙盘，只研究多槽或有真实标签的连续目标 | 连续目标来源由人确认，另立数据协议与基线；IV-2a 不伪造连续轨迹 |

M1 的“κ 不低于 LDA”是可行性假设，不是必须调到通过才能结项的绩效任务。若不成立，提交负结果和机制诊断后仍可结束阶段。M4 的断导建议在**预处理后的标准化输入**处定义缺失值，避免把原始波形置零后由滤波器制造额外瞬变；EEGNet/FBCSP 的等价处理要在 M0 评估层中事先声明。

## 10. 自动化、证据和人类阶段门

阶段内 agent 可自主提出单变量假设、建立隔离候选、运行快速/完整档、追加台账、保留负结果、提出 `status: proposed` 的 ADR 并生成阶段报告。每个任务的 receipt 至少绑定：项目与 cadence commit、依赖版本、数据文件哈希、stage/arm/subject/seed、完整参数、样本与试次计数、预测与标签、各相残差/合格率、证书、耗时和失败原因。独立 verifier 应从保存的预测和事件日志重算评分；缺 seed、缺试次或非有限值时失败，不以剩余行凑平均。

台账沿用 `results.tsv`：`commit stage arm kappa_val acc_val settle_rate seeds wall_s status description`。其余逐试次/逐相证据写入 receipt。候选 commit 必须有可追溯 Git ref；废弃候选不删除台账和日志。自动化不得在共享的脏工作树上执行 `git reset --hard`，应使用隔离分支或工作树。

每份 `reports/M<n>.md` 包含：台账区间、完整档候选、预设判据、验证结果、成本、负结果、crash、拒行/拒学、协议偏差、待决问题、下一阶段计划。没有真实数据和完整档验证时，只能称为设计或本地冒烟，不能称为阶段完成。

人负责接受/推翻 ADR、修改冻结评估层或组定义、决定首次读取 E、引入新数据集、跨被试预训练和 M5 连续目标来源。若不能在不越界的情况下继续，写入当前报告并推进不依赖该决定的工作。

## 11. 环境事实、风险和未决决定

当前平台为 Windows + PowerShell、无 NVIDIA GPU；用 Python 3.12 和 cadence CPU/Numba `[fast]`。2026-10-15 的环境审计见 cadence-net 0.83.0 (`6499e56`)、MOABB 1.7.2、Braindecode 1.8.1、scikit-learn 1.9.1。A01 T-only 路径曾只请求 `A01T.mat`，解析出 6 个有事件任务 run、每 run 48 试次、22 EEG + 3 EOG；这只是数据边界冒烟，**不是** M0 基线或任何模型验收。依赖变更后重新核对 cadence API 与 MOABB 数据加载路径。

在执行新方案前，人需要明确接受或保留现有规定，尤其是：E 是否延后至最终门、组 3 是否移除 Trace、M0 是否提前冻结试次评分，以及新对照和搜索上限是否纳入正式协议。随后还需依据数据说明核定三段无事件记录的用途、冻结 artifact 规则和五脑区导联映射；跨被试预训练与 M5 连续标签保持独立的人类决策。未解决项不得由 agent 以“默认合理”替代。
