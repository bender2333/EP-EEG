# M8 — 连续时间线 + 五分类（含静息）+ 单人 vs 三人串联（脚手架，未跑完整档）

状态：代码与冒烟就绪；完整档（100 epoch）等 M7 释放 CPU 后用 `automation/m8.sh` 启动。

## 数据
BCI IV-2a（MOABB `BNCI2014_001`），只读 T 会话（`eval/t_only_bnci.load_t_session`），E 不碰。

## 输入构造（`ep_eeg/m8_data.py`）
- 每个 run 整段连续信号：去均值 → EOG 回归 → 4–35 Hz 零相移带通 → 逐导联 Z-score（只在训练 run 上拟合）。
- 不切子窗、不做 Hjorth：每 25 个原始采样（100 ms）为一个时间步，drive = 22×25 = **550 维**，不下采样；再按训练步做逐维标准化 + tanh(x/3)。
- 逐步标签（trial onset = 注视十字，提示 +2 s，MI 到 +6 s，之后 1.5–2.5 s 间歇）：
  - 类 0–3：步完全落在 [onset+2.5 s, onset+5.5 s)（与 M0–M7 同窗）
  - 类 4 静息：步完全落在 [onset+6.5 s, 下一 onset)（MI 结束后留 0.5 s 余量，下一注视十字前结束；只取同一 run 内两试次之间）
  - -1：注视/提示 0–2.5 s、5.5–6.5 s、run 首尾——**照常输入以保持时间连续，权重 0 不施加 nudge**
- A01 实测：训练时间线 15476 步（MI 192 试次、静息间隙 188 段，静息步 2728），验证 7738 步（96 + 94）。
- 三人串联：A01|A02|A03 首尾相接，各人用各自的预处理拟合。

## 训练（`ep_eeg/m8_train.py`）
- 沙盘同 M1 g1（k=4，88 微柱），出水口 5；M1 最佳 opts（leak 1.0, rowmass 0.9, eta 0.5, temperature 0.01, sigma_in 0.012），100 epoch。
- 时间线切成 32 条等长连续流并行；每步 `Learner.step(..., warm=上一步 free 态, weight=标签掩码)`；未标注步只做 free 结算推进状态。run / 被试边界与被拒步处 warm 重置。
- 臂：`ep_m8_single`（每人一个网络）、`ep_m8_triple`（三人共享一个网络）。

## 评分
按事件（MI 试次或静息间隙）对合格步出水口活动求均值后 argmax：`kappa5`（五类）与 `kappa4_mi`（只 MI 试次、只在 0–3 号出水口里 argmax，可与同输入 LDA 0.389 对比）。同时报合格率。

## 冒烟
A01 截取 640 训练步 / 400 验证步、1 epoch、batch 8：证书通过、0 拒、合格率 1.0，5 出水口、550 维，流程打通（κ 无意义）。

## 内部状态功率谱
沿用 `ep_eeg/state_psd.py` 的方法（滑动 1 采样驱动得到 250 Hz 状态序列、Welch、mu/beta、C3/C4 ERD），完整档训练后接入。
