协议差异必须写清楚。公开数字大多来自 T→E 跨会话（288 个训练试次），或 MOABB 的会话内 5 折交叉验证（约 230 个训练试次）；本项目用的是会话内按时间切分，只有 192 个训练试次。所以这条规则判的是数量级是否一致，不是严格的同协议复现。准确率换算成 κ 时用 κ = (acc − 0.25)/0.75（四类均衡）。

**与指令的偏差（提交前就已写明）**：指令说 B「用已存权重，零训练算力」。但已存权重只有 seed 0，而声明规则要求至少 3 个种子。所以两个训练湖的 seed 1、2 需要重训。M9 时序网完全没有存权重，只能用未训练的储备池，外加一个便宜的 BPTT 重训版本。重训用的是当前代码。先**用同一代码重训 seed 0**，与已存权重逐元素比较：如果最大绝对差 ≤ 1e-9，就认为可复现；否则如实报告差值，seed 0 仍然用已存权重。

每个基底在已存权重或训练后的权重上都要记录：证书是否通过、行质量、柱状态对输入的线性拟合 R²，以及饱和比例（|v|>2 的比例）。

**输入层参照**（同一套读出程序，直接作用在基底的输入上）：
- `input_track2`：静态湖的输入，即 Track-2 本身（每个子窗 66 维）；
- `input_rawseg`：M9 时序网的输入，即冻结评估层的原始段信号，按 M9 的编码。

### 4.2 读出（oracle）

在各基底的柱状态上（时序网用隐状态 tanh(h)）做闭式或凸的读出：

- **特征映射**：
  - `F_mean`：对 11 个子窗取平均；时序网对 t ≥ 25 步取时间平均。
  - `F_cat`：11 个子窗首尾拼接；时序网把 t ∈ [25, 375) 等分成 10 段，每段取平均后拼接。
  - 以上都在训练集上按维 z-score。
- **分类器与正则网格**：
  - ridge：α ∈ logspace(−3, 4, 15)；
  - shrinkage LDA：Ledoit-Wolf 自动收缩，外加固定收缩 {0.01, 0.1, 0.3, 0.5, 0.7, 0.9}；
  - L2 逻辑回归：C ∈ logspace(−4, 3, 15)。
- **两个上限**：
  - **诚实上限 κ_cv**：在训练集（192 个试次）上做 5 折分层交叉验证，同时选出分类器、特征映射和正则强度；用全部训练集重拟合，在验证集上评一次。
  - **oracle 上限 κ_or**：直接取整个网格在验证集上的最大值。这一步用到了验证标签，是**有意偏乐观**的上界。
- **非线性 oracle 参照**（只作用在 `input_track2` 上，不进判据）：RBF-SVM（C ∈ logspace(−2, 3, 6)，γ ∈ {0.3, 1, 3}/d），以及 kNN（k ∈ {5, 15, 45}）。它估计的是 Track-2 里对非线性读出可用的信息量。

### 4.3 判据（预注册）

参照数是 FBCSP 的 κ_val：0.483（M0，9 人 × 3 个种子，冻结协议）。

- **B-1**：对每个基底 S，计算 9 名被试的 κ_or(S)（先在种子上取平均）的均值，看它是否 < 0.483。
- **只有所有基底都满足 B-1 时**，报告才写入下面这句话，并附上它的适用范围：
  > 换任何学习规则都不能让该基底超过 FBCSP。
  - **线性工作区内的基底**（柱状态对输入的线性 R² > 0.99）：在线性工作区内，湖的状态是输入的仿射变换，读出又是线性的，所以线性读出的上限不会超过 `input_track2` 的上限，只会因有限样本下正则几何不同而略有差别；差别大小用 `random_lake` 与 `input_track2` 之差来估计。所以只有当 κ_or(`input_track2`) 也 < 0.483 时，这句话的范围才能写成「对任何使湖保持线性工作区的权重」。否则只能写「对所测权重」。
  - **非线性基底**（m64、M9）：只适用于所测的权重和这个读出族。
- 只要有一个基底不满足 B-1，这句话就不写，报告列出哪些基底的上限达到了 FBCSP。由于 κ_or 偏乐观，这种情况本身只说明「不能排除」。
- 另外报告：每个基底的 κ_cv 和 κ_or 的被试级数值；κ_or(S) 低于 FBCSP 的被试数；被试级配对 Wilcoxon；贝叶斯层级模型给出的 κ_or(S) − κ_FBCSP 的 95% 区间。
- 总表把 B 的全部上限与 A 的三个基线、M0 的 FBCSP/EEGNet/同输入 LDA 并列。

## 5. 步骤 C：同构性检验（Q2 的判据）

C 最后做。它会撞上 G3 发现的谱半径失控，所以把谱半径投影作为预注册的自变量正式登记，有投影和无投影两臂并列跑，**不再当作事后挽救**。

### 5.1 数据（新数据层 `ep_eeg/gdf_data.py`）

- **读入**：只读 `A0xT.gdf`。22 导 EEG，3 导 EOG，250 Hz。
- **完整性核对**：对每名被试，把 `.gdf` 中 6 个运动想象 run 的试次段，与冻结评估层用的 `.mat` 逐样本比较。要求相关 ≥ 0.999，且标签完全一致；任何一名被试不满足就停下记账。
- **EOG 回归**：系数用**标定段**（有几段用几段；A04 只有 1072）拟合，然后作用于全程。这只是 C 的数据层；A 和 B 仍按 ADR-0005 处理。
- **滤波**：**因果**四阶 Butterworth 带通 1–45 Hz，逐 run 处理。用因果滤波是为了避免零相位滤波把未来的样本漏进当前样本，否则预测任务会虚高。
- **降采样与标准化**：降采样到 125 Hz（隔点取样，45 Hz 低通已经抗混叠）。逐导联 z-score，统计量只用 run 0–3。
- **训练集**：run 0–3 的连续信号，包括试次间静息。**排除**与 1023 标记试次重叠的部分（从试次起点到下一试次起点）。标定段不进训练。
- **验证集**：run 4–5 的连续信号，以同样的方式排除 1023 段，只对剩下的部分计分（状态仍会连续走过被排除的部分）。
- 训练子集与选择子集：run 0–2 训练、run 3 选择，只用于下面 §5.2 的输入编码选择。

- **输入编码**（M9 的形式）：u = gain·tanh(z/3)，外加一个常数端口。gain ∈ {1, 3, 10}，端口 ∈ {0, 1, 5}，在 run 0–2 / run 3 上按 `C_res` 的 h=1 R² 选出，之后所有网络 arm 共用。VAR 直接用 z。
- **训练目标**：所有模型都只学一步预测，即输入 z[≤t]，目标 z[t+1]，逐步二次损失（EP 的 `nudge` 为二次，目标就是 z[t+1]）。多步预测一律闭环迭代：把模型自己的预测再编码成下一步的输入。
- **EP/BPTT 超参**（沿用 G3，不另选）：β 0.05，Adam lr 0.003，batch 16，随机裁剪 125 步（1 s）。每段裁剪从零态开始，前 25 步不施加目标（目标设为自由输出）。
- **更新次数 U（预注册规则）**：在 A01、seed 0 上先跑 20 次更新，**只读耗时，不读任何指标**，得到每次更新的平均耗时 t̄。然后取 U = min(400, ⌊7200 s / t̄⌋)，在任何正式的 C 运行之前固定下来，所有 EP 和 BPTT 运行都用这个 U。若 U < 200，报告要标明 C「受算力限制、检验力不足」，并在待决问题里请人决定是否加预算。
- **种子**：网络 arm 用 0、1、2（种子决定 A/B 初值和裁剪顺序）。VAR 是确定性的。
- **训练过程监控**：每 U/8 次更新，在固定的一段 60 s 验证数据上记录 h=1 的 R²。这只是监控，**不用于选点**；最终取最后一次更新的网络。

### 5.3 指标

1. **预测 R²**：
   - 在验证集上，每隔 25 个样本（0.2 s）取一个预测起点。先用真实输入把状态推到起点，再闭环预测 h ∈ {1, 5, 25, 125} 步（8 ms、40 ms、0.2 s、1 s）。
   - R² 逐导联计算，再在导联上平均。
   - 主量是 R̄² = 四个视界的平均。
2. **生成统计**：
   - **生成方式**：每个模型闭环运行，每步加上新息 ε ~ N(0, Σ̂)，Σ̂ 是该模型在训练集上一步残差的协方差。从验证集的 4 个随机时刻起步，各跑 62 s，丢掉前 2 s。
   - **对数谱距离 LSD**：Welch 谱（窗长 2 s，重叠 50%）。对每个导联，计算 2–40 Hz 上 10·log10 P_gen − 10·log10 P_real 的均方根，再在导联上平均，单位 dB。
   - **滞后相关距离 LCD**：在 τ ∈ {0, 1, 2, 4, 8, 16, 32} 个样本上，算出 22×22 的滞后相关矩阵 R(τ)。LCD = 在各 τ 上取 ‖R_gen(τ) − R_real(τ)‖_F / ‖R_real(τ)‖_F，再平均。
   - **归一化**：用真实数据 run 0–3 对 run 4–5 的 LSD_rr 和 LCD_rr 作为「真对真」的底。D_gen = ½(LSD/LSD_rr + LCD/LCD_rr)。D_gen = 1 表示模型生成的信号和另一段真实 EEG 一样接近验证数据。
   - **分解量**（报告，不进判据）：
     - mu 峰（8–13 Hz）和 beta 峰（13–30 Hz）的频率，以及高出非周期拟合的高度；
     - 1/f 斜率：在 2–7 Hz ∪ 30–40 Hz 上对 log10 P 和 log10 f 做线性拟合；
     - 以上各量与真实数据的绝对差。
   - 模型发散（出现非有限值）时，R² 记为 −∞，D_gen 记为 +∞，并在台账中写明。

### 5.4 判据（预注册）

- **同构性**：
  - 对被试 s（先在 3 个种子上取平均），EP arm 记一次「胜」，当且仅当：
    - R̄²_EP > max(R̄²_var6, R̄²_res)，**并且**
    - D_gen,EP < min(D_gen,var6, D_gen,res)。
  - 两条 EP arm（`C_ep_proj`、`C_ep_noproj`）中**任意一条**在 **≥ 7/9** 名被试上胜出，才称「同构性成立」。
  - 两条 arm 是两次比较，报告中注明这一点。
  - 每个子指标的胜负数、Wilcoxon 和贝叶斯区间都单独报告。
- **投影是否解决稳定性**。按 arm 统计 27 个运行（9 名被试 × 3 个种子），记录：
  - (i) 接受率，即被接受的 observe 次数 / 尝试次数；
  - (ii) 训练中 ρ(A) 的最大值；
  - (iii) 是否「崩塌」：最后一个监控点的 R²(h=1) 比训练中最好的监控点低 0.05 以上。

  「投影解决了稳定性」需要同时满足三条：
  - `C_ep_proj` 至少 25/27 个运行的接受率 ≥ 0.98；
  - `C_ep_proj` 至少 25/27 个运行不崩塌；
  - `C_ep_noproj` 至少有 3 个运行违反上面两条之一。

  如果 `C_ep_noproj` 本身就稳定，结论写「这个任务上没有需要解决的不稳定」，不算投影的功劳。
- **C0（回答 M10 留下的问题「长时程积分的稳定性能否在 cadence 时序模块内解决」）**：
  - **设置**：在 G3 玩具上原样重跑 orth-adam，只多加 ρ(A) ≤ 0.95 投影。种子 0、1、2，测试划分，2000 次更新，代码 `ep_eeg/g3_toy.py` 加一个投影开关。
  - **判据**：沿用 G3 的预注册判据，即测试 R² 均值 ≥ 0.8；另加接受率 ≥ 0.95。两条都满足，才写「在 cadence 时序模块内，用谱半径投影可以解决」。
  - **算力**：G3 实测每次更新 7.5–9.5 s，3 个运行并行约 5 h；单个运行超过 2 × 20,000 s 记 crash。

### 5.5 C 的算力预算

- **G3 实测**：H=16 时每次更新约 3–11 s。H=44、22 个输出时，预估慢 1–3 倍。
- **预算规则**：单个 EP 运行的预算固定为 7200 s；超过 14,400 s 记 crash，crash 时保留已写出的监控点。
- **总时长**：EP 共 54 个运行，4 核并行，至多约 27 h。BPTT 共 54 个运行，约 1 h。VAR 和储备池只需几分钟。C0 约 5 h。
- **合计**：C 至多约 33 h（墙钟）。

## 6. 步骤 D：信用分配检验（Q3 的判据）

G1 已经发现：cadence 的 EP 更新是两端活动的乘积，所以 `untied` 与 `recip` 的结果逐位相同，「去掉互惠绑定」是一个空消融。D 不再用它，改用两种真正非退化的对照：
- 一种是**结构**：隐层带递归的小图、motor 之间的可塑互惠边。
- 一种是**训练器**：同一结构，改用精确隐式梯度训练（对静态平衡网络，这等价于收敛后的 BPTT，也就是递归反向传播）。

### 6.1 D1：小型可控图上的数值检验（把 `ep_eeg/gradcheck.py` 扩成完整报告）

- **图**：
  - 6 个源神经元，单向投射到 10 个隐层自由神经元；
  - 隐层之间全连通互惠，隐层与 3 个输出之间互惠；
  - 没有输入到输出的直连。
  - 神经元模型为 `learning_neuron_model(leak=1.0)`（光滑的 tanh(v/2)）；另做 leak=0.1（默认值，在 0 处有折点）作为次要条件。
- **三个梯度**：
  - `g_EP`：cadence `Learner` 的中心化 ±β 对比，按 cadence 文档的定义（估计 −∂L/∂W）；
  - `g_IFT`：隐式梯度，从 cadence 的 `implicit_gradient` 移植，推广到二次 nudge；
  - `g_FD`：自由平衡损失的中心差分，h = 1e-4，容限 1e-11。
- **损失**：交叉熵 nudge 对应 T·CE（T = 0.1），二次 nudge 对应 ½‖s − target‖²。
- **度量**：
  - 余弦 cos(EP, IFT)、cos(EP, FD)、cos(IFT, FD)；
  - 相对误差 ‖g_EP − g_IFT‖/‖g_IFT‖；
  - 尺度比；
  - 以上都按边类别分开报告：deep（源→隐层）、lateral（隐层↔隐层）、readout（隐层↔输出）、bias。
- **网格**：
  - β ∈ {0.1, 0.04, 0.01, 0.0025}
  - 容限 ∈ {3e-3（生产值）, 1e-4, 1e-6, 1e-9}
  - 行质量预算 L·ρ_W ∈ {0.3, 0.6, 0.9}
  - 输入幅度：线性区（drive × 0.5），或饱和区（drive × 4，记录饱和比例）
  - nudge ∈ {CE, 二次}
  - leak ∈ {1.0, 0.1}
  - 种子 0, 1, 2
  - 每格用 16 个随机输入
- **对称性破缺扫描**（次要）：`reciprocal=False`，反馈权重 = 前向权重 × (1 + ε·ξ)，ε ∈ {0, 0.1, 0.3, 1.0}，取生产值的 β 和容限。用来展示失去对称后 EP 的估计如何变差。
- **真实图**：原 gradcheck 用的 k=1 沙盘、A01 数据，加上 IFT 对照。
- **判据 D1（预注册）**：
  - 在 leak=1.0、生产设置（β 0.04，容限 3e-3，中心化）下，每个（行质量 × 区域 × nudge）格子都要满足：
    - 3 个种子平均的 cos(EP, IFT) ≥ 0.9，对全部参数成立；
    - 对 deep 类单独也 ≥ 0.9。
  - 所有格子都满足 → D1 成立；只有部分格子满足 → 「部分成立」，列出不满足的格子；都不满足 → 不成立。
  - **有效性前提**：cos(IFT, FD) ≥ 0.99。不满足时，D1 记为「无效」，不记为「不成立」，并先修实现。
  - 同时报告余弦降到 0.9 以下时的 β-容限边界。

### 6.2 D2：读出微问题，非退化结构，3 个种子

- **特征**：G1 的 F_lake（M6 随机湖 seed 0 的柱激活，88 维），同特征 ridge 参照 0.352（G1）。
- **结构**：
  - `recip`：G1 结构，88 个特征神经元是自由的，与 4 个 motor 互惠；
  - `lateral`：特征为源，单向投射到 motor，motor 之间有可塑互惠边，初值 0；
  - `recip_lat`：recip 再加 motor 之间的可塑互惠边。
- **超参**：三个结构都用 G1 在内部切分上为 `recip` 选出的那一组：交叉熵 T=0.1，η=0.05，sub 行模式，100 epoch，证书和行和投影与 G1 相同。不另选超参。
- **训练器**：
  - `EP`：cadence `Learner`；
  - `IFT`：同一结构、同一批次顺序、同一步长约定、同一裁剪和投影，只把更新换成 −η·g_IFT。步长约定与 cadence 的 EP 更新一致，以 D1 测得的尺度比 ≈ 1 为准。
- **种子**：3、4、5。之所以用新种子，是因为 G1 已经看过 `recip` 在种子 0–2 上的结果（+0.029）。
- **判据 D2a（指令给定）**：`recip` 结构用 EP 训练，与同特征 ridge 的差距 ≤ 0.03（3 个种子 × 9 名被试的平均）。**披露**：同一配置在种子 0–2 上已经见过 +0.029，所以这条判据不是盲的。
- **判据 D2b（Q3 的任务层判据）**：对 `recip` 和 `recip_lat`，都要求 |κ_EP − κ_IFT| ≤ 0.03（平均）。满足则写「EP 与隐式梯度在任务层面等价」。同时报告 `lateral` 的结果和逐被试的配对差。
- **Q3 的总结论**：
  - D1 成立且 D2b 成立 → 「EP 信用分配在非退化结构里有效」；
  - D1 成立而 D2b 不成立 → 「局部梯度方向正确，但任务层面不等价」，并给出 D2 中差距的来源诊断；
  - D1 不成立 → 「无效」，并给出边界。
  - D2a 单独报告，不替 Q3 下结论：它衡量的是「能不能学到最优读出」，不是「是不是梯度」。
- **算力**：D1 约 1 h。D2 共 162 个运行（3 结构 × 2 训练器 × 9 被试 × 3 种子），约 2.5 h。

## 7. 统计（所有步骤通用）

- 每个比较都报告：被试级数值、配对 Wilcoxon（双侧）、均值差和配对秩双列相关（effect size）。
- **贝叶斯层级模型**（新增）：
  - **模型**：设被试 s 在种子上取平均后的差值为 d̄_s，标准误 σ_s（用跨被试合并的种子内方差算出，下限 1e-3）。d̄_s ~ N(μ + u_s, σ_s²)，u_s ~ N(0, τ²)。
  - **先验**：μ 取平坦先验，τ ~ HalfCauchy(0, 0.1)。
  - **计算**：仿照 BDA 的「八校」例，先在网格上精确计算 p(τ | 数据)，再求 μ | τ，得到边缘后验。不用 MCMC，结果确定。
  - **报告**：μ 的后验均值、95% 可信区间和 P(μ > 0)。
  - **实现**：`ep_eeg/stats_util.py`。

## 8. 步骤 E：植入真值（阳性对照，可以与 A、B 并行）

**说明**：人在指令中给出的 E 的描述在消息里被截断了，只剩「E 植入真值独立于以上，可以和 A、B 并行」，以及 A、B、D、E 只用静态 NeuralGraph 或闭式方法。下面是 agent 补全的设计，已列入待决问题。人如果原本有别的意图，按「事后修改」节更正。设计原则是：给每条问题的判据配一个**已知答案的阳性对照**，用来检验度量本身能不能看出植入的结构。

- **E1（Q1，闭式）：合成 EEG，植入源**
  - **数据格式**：9 个合成「被试」，格式与 2a 相同：22 导 + 3 导 EOG，250 Hz，6 个 run，每个 run 48 个试次，四类均衡。数据直接交给冻结评估层的预处理函数。
  - **植入的源**：4 个任务源，按左手、右手、足、舌分别放在 C4、C3、Cz 附近和双侧 C5/C6。另有 8 个背景源。每个源包含 10 Hz 和 20 Hz 的窄带振荡，外加 1/f 背景。
  - **类别效应**：类别 c 在提示后 0.5–4 s 内，把源 c 的振荡幅度降低到 (1 − e) 倍。
  - **前向模型**：电极平面上的高斯斑，宽度 σ_mix 取「窄」（≈ 每个源只落在一个导联上）或「宽」（容积传导）。传感器噪声为 1/f。EOG 弱混入额区。
  - **标定**：e 从 {0.1, 0.2, 0.3, 0.5} 中选，用「真值 oracle」（真实源在 mu/beta 带的对数功率 + LDA）在内部切分上的 κ 在 0.5–0.7 之间。这一步只用合成数据，不碰真实数据。
  - **测量**：真值 oracle、FBCSP、TS+LR、MDM、Track-2 + sLDA、`random_lake` 的上限（B 的程序）、`input_track2` 的上限。
  - **预注册预测**：
    - P1：窄混合下，|Track-2 上限 − FBCSP| < 0.1。
    - P2：宽混合下，Track-2 上限比 FBCSP 低 0.1 以上。
    - P3：两种混合下，|`random_lake` 上限 − Track-2 上限| ≤ 0.03。
  - **用途**：P1–P3 都成立，就在植入真值上验证了 B 的解释，即上限受输入编码限制，不受学习规则限制。如果 P2 不成立，真实数据上的差距就不能用空间混合来解释。
- **E2（Q3，静态 NeuralGraph）：植入教师**
  - **教师**：与 D2 的 `recip_lat` 结构相同，权重是植入的：motor 之间强互惠，输入到 motor 是稀疏的强连接（密度 10%）。
  - **数据**：输入是 G1 的 F_lake；标签取教师自由平衡的 argmax，所以学生的函数类里一定存在完美解。
  - **学生**：同一结构，随机初值，分别用 EP 和 IFT 训练，用 D2 的超参，种子 0、1、2。
  - **测量**：
    - 学生与教师在验证集上的一致率；
    - 植入边的恢复 AUC：用 |学到的权重 − 初值| 区分植入边和非植入边；
    - 训练过程中 cos(Δθ_EP, Δθ_IFT)。
  - **预注册预测**：
    - EP 学生的一致率 ≥ IFT 学生的 0.9 倍；
    - AUC_EP ≥ AUC_IFT − 0.05。
- **E3（Q2，闭式）：度量的阳性对照**
  - **合成序列**：在 A01 的 run 0–3（只用训练部分）上，生成三段与 C 预处理后同形状的序列：
    - (a) 拟合好的 VAR(6) 用新息驱动生成；
    - (b) 一个未训练的 M9 结构 `TemporalPatchNet` 教师，ρ(A) = 0.95，由噪声驱动，输出映射到 22 导；
    - (c) 真实数据本身。
  - **方法**：只用闭式方法（VAR(6)、`C_res`）拟合，计算 C 的全部指标。
  - **预注册预测**：在 (a) 上 VAR 胜，在 (b) 上储备池胜。两条都成立，说明 C 的度量能区分模型类别；否则 C 的判据结论要打折扣，并在报告里写明。
- **算力**：E1 约 30 min，E2 约 1 h（54 个运行），E3 约 15 min。

   - 与「成对对称化后的梯度」的余弦为 1.000 / 1.000 / 0.999 / 0.995（ε = 0 / 0.1 / 0.3 / 1）。

   也就是说，EP 的对比量是两端活动的乘积，它估计的是**成对共享权重**的梯度，不能区分两个方向。这是 G1 中 `untied` 与 `recip` 逐位相同的机理：一个未绑定的网络得到的更新，和绑定的网络完全一样。

|---|---:|---:|---:|---|
| cos(EP, IFT) | 0.825 | 0.975–0.976 | 0.9999 | 容限 3e-3 时为 0.0；容限 ≤ 1e-4 时为 1.0000 |

1. **不对称在训练中被抹掉了。**

   - 机制分两步。第一，EP 的对比量是两端活动的乘积，所以每一步对一对突触的两个方向施加完全相同的增量（6600 步逐步检查，两个方向的增量之差 ≤ 3e-17）。这时初始的不对称只以一个加性常数保留下来：在第 345 步行质量投影首次触发之前，‖w_fb − w_fw‖ 一直是 0.198。第二，投影触发之后（这个运行中共 5188 次），每次投影都按比例缩小权重，加性的不对称随之几何衰减：第 500、1000、2000 步分别为 0.179、0.100、0.028，结束时为 8e-5。与此同时，对称部分不断由 EP 的更新补充，‖w_fw‖ 稳定在 0.50。

2. **在这个读出结构里，反馈对预测没有作用。** 把训练好的学生的全部 motor→relay 反馈权重置零，96 个验证试次的预测一个都不变：EP 学生和 asym 学生都是如此，一致率都保持 0.719。
