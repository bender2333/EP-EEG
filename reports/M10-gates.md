# M10 门槛实验（G1–G3）：预注册

状态：**预注册，尚未运行**。本文件在任何 G 实验运行之前提交。三个门槛全部通过，才写 M10 的 ADR。分支 `m10-gates`，基于 M9 收口后的 `auto-run`。协议不变：只用 T 会话，run 0–3 训练，run 4–5 验证，不读取 E。凡是需要在多个配置中选择的地方，都在训练集内部切分（run 0–2 拟合，run 3 选择），选定的配置再用 run 0–3 重新训练，在 run 4–5 上判定。预处理的统计量仍按冻结层在 run 0–3 上拟合，这是一处无监督的轻微泄漏，如实记录在此。

## G1：读出微问题（最关键）

**问题**：特征固定，证书约束下的 EP 能否把四分类读出学到与同特征 ridge 相差 0.03 以内？这是一个纯优化问题，与冲刷无关。

**特征（固定，不训练）**：
- **F_lake（主）**：M6 配置下随机线性湖（seed 0）的柱激活，共 88 维，读出参数为 88 × 4 = 352 个。
- **F_raw（次）**：Track-2 原始特征，66 维，读出参数为 264 个。

两种特征都按训练行逐维 z-score。EP 中特征作为外部驱动 z 进入网络，经过 ρ 后为 ρ(z) = tanh(z/2)（leak = 1.0）。参照 ridge 用**同一个** ρ(z)：在子窗上取试次平均，标准化后用 `RidgeClassifierCV`。这样 EP 和参照看到的是完全相同的特征。

**结构变体（扫的是结构；η 只作为讨厌参数）**：
- `recip`：特征驱动 d 个自由的中继神经元，中继与 4 个 motor 之间互惠绑定（沙盘读出拓扑）。
- `untied`：拓扑与 `recip` 相同，但用 `Learner(reciprocal=False)`，正向和反向突触各自有效能（去掉互惠绑定）。
- `oneway`：特征为源神经元，单向投射到 motor。没有 free→free 边，按 ADR-0012，证书总是成立。**注意**：此时 EP 退化为 delta 规则。
- `lateral`：在 `oneway` 的基础上，motor 之间加互惠可塑连接（6 对，初值为 0），使 motor 成为一个独立的小皮层。

其他轴：
- nudge ∈ {交叉熵 T = 0.01，交叉熵 T = 0.1，二次（MSE，目标为 one-hot 0/1）}
- η ∈ {0.05，0.5}
- 训练行 ∈ {子窗行（2112 行，100 epoch），试次平均行（192 行，1100 epoch，更新次数与子窗行相同）}

两种特征共 2 × 4 × 3 × 2 × 2 = 96 个配置。其余设置沿用 M6：β = 0.04，batch 32，free / nudged 步数 1024，tol 3e-3，`qualified=True`，行和投影 0.9/L（只计证书所计的边），`scale_cap` 3，motor 初值 σ = 0.01。

**选择**：对每种特征，在内部切分上（run 0–2 训练，run 3 评估）用 seed 0 计算每个配置的差距 = ridge κ − EP κ（9 人平均），取差距最小的配置。

**判据（锁定）**：在 F_lake 上，选定的配置用 run 0–3 训练、在 run 4–5 上评估，3 个种子（0、1、2）的平均差距（9 人平均 ridge κ − EP κ）≤ **0.03**；同时所有运行每个 epoch 末的证书都成立，学习接受率 ≥ 98%。
- 只有 F_lake 决定 G1 是否通过；F_raw 只报告。
- 如果只有 `oneway`（delta 规则）通过，G1 记为"通过（退化形式）"：M10 的读出必须是单向的，而且这一结果不能说明 EP 在递归网络中的信用分配有效。

## G2：学习曲线

**问题**：线性湖上，训练湖 + ridge 与随机湖 + ridge 的差距是否随训练试次数 N 拉开？

- N ∈ {48，96，144，192}：从 run 0–3 中按类分层抽取，抽样种子 r ∈ {0，1，2}。湖的初始化种子也取 r，所以随机湖就是训练湖的初值。验证集固定为 run 4–5 的全部 96 个试次。
- 训练湖使用 M6 配置全训，更新次数固定为 6600（epoch = 100 × 192 / N），使 N 只改变样本数，不改变更新次数。
- 两个湖都用相同的 ridge 闭式读出（子窗试次平均，标准化，`RidgeClassifierCV`）。
- Δ(N) = κ(训练湖 + ridge) − κ(随机湖 + ridge)，在 9 名被试 × 3 个抽样种子上取平均。

**判据（锁定）**：
- **样本量是瓶颈**，当且仅当同时满足：Δ(192) − Δ(48) ≥ **0.03**；并且 Δ 对 N 的最小二乘斜率（按被试先对 3 个抽样种子取平均）在 ≥ **7/9** 名被试上为正。此时 G2 **不通过**：M10 在 288 个试次上也会被卡住，需要先解决数据问题（例如把 T+E 合并做会话内交叉验证，只作为科学实验，不作为竞赛协议）。
- **否则**，样本量不是瓶颈，G2 **通过**。

同时报告随机湖 + ridge 自身的 κ(N) 曲线，它反映闭式读出本身是否受样本量限制。

## G3：时序可行性玩具问题

**问题**：cadence 的时序模块（`TemporalPatchNet` / `PartitionedTemporalPatchNet`）能否用 EP 从波形学出"平方 + 约 1 秒积分"？

**合成数据（125 Hz）**：
- 输入：x(t) = a(t)·sin(2π·10·t/125 + φ) + 0.05·ε，其中 φ 为随机初相，ε ~ N(0, 1)。
- 幅度 a(t) ∈ [0.1, 1]，是相关时间约 1 s 的平滑随机过程：对高斯白噪声做 0.5 Hz 低通，再映射到这个区间。
- 目标：y(t) = 2 · 过去 1 s（125 个样本）内 x² 的因果滑动平均，约等于 a²。
- 数据划分：训练 64 条、选择 16 条、测试 32 条序列，每条 4 s。指标为 t ≥ 125 的测试 R²。
- 网络有一个常数输入端口（M9：没有偏置时映射是奇函数，无法表示 x²）。

**参照（只报告，不参与判定）**：
- 线性 ridge：在 125 个滞后的 x 上回归（预期 R² ≈ 0，因为包络是偶函数）；
- 未训练结构 + ridge 读出（表示能力）；
- 同结构 BPTT（可训练性）；
- 两个分解子任务：只积分（输入换成 x²）和只平方（目标改为 0.1 s 平均）。

**变体**：A 初始化 ∈ {正交，对角}，优化器 ∈ {EP 增量直接更新，EP 梯度 + Adam}，H = 16，crop 长度 250 步，batch 16，共 2000 次更新。用选择集上的 R² 选出最佳变体，再用 3 个种子在测试集上判定。

**判据（锁定）**：选定的 EP 变体（C 从随机初始化开始，不用 ridge 初始化）在测试集上 3 个种子的平均 R² ≥ **0.8**。不通过 → 原始波形路线不可行，物理隐喻需要换底层库。

**改动**：
1. **不再做选择阶段**。判定变体定为 **orth-adam**，依据是上面的中途值，这本身属于看过数据之后的选择，在此披露。orth-sgd 也在测试集上跑 3 个种子，只报告，不参与判定。diag 初始化因为成本太高而放弃。
2. **EP 只跑主任务**（平方 + 积分）。两个分解子任务只保留闭式和 BPTT 参照（线性 lag ridge、储备池 ridge、BPTT），不跑 EP。

## G1 结果：**通过（退化形式）**

选择阶段：内部切分（run 0–2 训练，run 3 评估），96 个配置 × 9 名被试，seed 0。学习接受率都是 1.000，证书都没有失败。回执在 `receipts/G1/85ac26b/select.json`。
- F_lake 中差距最小的是 `oneway / mse / η 0.5 / trial`，差距 −0.056。
- 非退化结构中最好的是 `recip / ce T=0.1 / η 0.05 / sub`，差距 −0.022。
- 沙盘原配置（`recip / ce T=0.01 / η 0.5 / sub`）的差距为 **+0.201**。

最终判定：run 0–3 训练，run 4–5 评估，3 个种子 × 9 名被试。全部学习接受率 1.0，证书没有失败，拒学 0 次，验证合格率 1.0。回执在 `receipts/G1/79c4198/final.json`。

| 配置 | EP κ（种子标准差） | 同特征 ridge | 差距（种子 0/1/2） | EP ≥ ridge 的被试 |
|---|---:|---:|---|---|
| **lake / oneway / mse / 0.5 / trial（预注册判定）** | 0.352（0.002） | 0.352 | **+0.000**（+0.003 / −0.002 / −0.002） | 4/9 |
| lake / recip / ce0.1 / 0.05 / sub（探索，非退化） | 0.323（0.005） | 0.352 | +0.029（+0.029 / +0.023 / +0.035） | 2/9（6 负） |
| raw / lateral / ce0.1 / 0.05 / sub（F_raw，只报告） | 0.373（0.003） | 0.363 | −0.011 | 4/9 |

- **判据成立**：预注册配置的差距为 0.000 ≤ 0.03。按预注册的条款，这是**退化形式**的通过：读出是单向的，EP 在这里等价于 delta 规则，这个结果不能说明 EP 在递归网络中的信用分配有效。
- **非退化结构也进入了 0.03 以内**：互惠读出加 T = 0.1、η = 0.05，差距 +0.029，刚好压线，而且 6/9 名被试仍低于 ridge。这个配置是在内部切分上挑出来的，属于探索性结果。
- **更正 M9 的读出结论**：M9 中 EP 读出比 ridge 低约 0.10，主要原因是**学习率和温度**（沙盘的 η = 0.5、T = 0.01），而不是结构或证书。同一互惠结构下，只把 η 降到 0.05，内部切分上的差距就从 +0.201 缩到 +0.009（T = 0.01）。M9 的 B′ 只朝更低的 T 方向扫，方向错了，而且从来没有扫过 η。
- **参照数的说明**：这里同特征 ridge 用的是 ρ(z) = tanh(z/2)，即 EP 实际看到的特征，得分为 0.352，比 M9 中直接对柱激活做 ridge 的 0.366 低 0.014。这 0.014 是输入经过 ρ 压缩造成的，不是读出学习造成的。
- `untied` 与 `recip` 的结果逐位相同，原因是 EP 的对比量是两端活动的乘积，两个方向得到的更新完全一样。所以"去掉互惠绑定"在学习规则层面不起作用。

## G2 结果：**通过**（按预注册规则，样本量不是瓶颈）

9 名被试 × 3 个抽样种子 × 4 个 N，共 108 次运行。学习接受率都是 1.0，证书全部通过，验证合格率 1.0，更新次数为 6400–6600。回执在 `receipts/G2/2ed8bea/runs.json`。

| N | 随机湖 + ridge | 训练湖 + ridge | Δ | EP 自身读出（参考） |
|---:|---:|---:|---:|---:|
| 48 | 0.213 | 0.241 | +0.027 | 0.252 |
| 96 | 0.295 | 0.307 | +0.012 | 0.300 |
| 144 | 0.330 | 0.338 | +0.008 | 0.306 |
| 192 | 0.362 | 0.357 | −0.005 | 0.335 |

- Δ(192) − Δ(48) = **−0.032**，按被试计的斜率只有 **2/9** 为正，不满足"差距拉开"的两个条件，所以 **G2 通过**。
- **方向和预想相反**：差距随 N 增大**缩小**，不是拉开。训练湖只在小样本时略好于随机湖（N=48 时 +0.027），更像一种正则化；N=192 时优势消失（与 M9c 的 1 胜 5 负 3 平一致）。
- **限定（不影响判据）**：闭式读出的绝对水平受样本量限制很明显。随机湖 + ridge 从 0.213 一路升到 0.362，N=192 时每多 48 个试次仍提高约 0.03，没有进入平台。所以 G2 只说明"EP 训练的收益不随样本量增长"；它**不说明** 288 个试次对 M10 的解码水平已经足够。
