# M12 双湖 v2：在三个条件同时满足时检验河道假设（预注册）

状态：**预注册**，写于 2026-10-19。分支 `M12`，从 `m11`（`48321ab`）分出。指令原文：人于 2026-10-19 给出的《M12 双湖 v2：Scale 到底的执行指令》（下称「指令」）。本文件第一次提交时，M12 还没有运行任何实验：没有改 cadence、没有训练、没有评估、没有读取任何 M12 指标。提交之后对已提交预注册内容的任何改动，都写进文末的「事后修改」节，并标明时间、原因，以及改动前是否已看到相关结果。

## 0. 总述

### 0.1 问题

在带收敛证书、只用局部学习的 EP 湖上，当**输入**（原始窗 + 时间平移共享）、**非线性**（光滑偶分量神经元）、**样本量**（EA 跨被试合并）三个条件同时满足时，湖能否从原始 EEG 自己冲刷出跨导联的功率/协方差结构（河道），并在准确率上与 FBCSP、EA+TS+LR 持平。M0–M11 从未同时满足这三个条件。

「走到底」：三个条件逐一补齐后，在 ≥ 2 个数据集、≥ 60 名被试上得到明确的是或否。

### 0.2 胜利条件（全部满足才算成立）

- **V1 表征**：EP 训练湖 + ridge 在 2a 被试内 ≥ 7/9、LOSO ≥ 7/9 留出被试上超过同配置随机湖 + ridge，边际 ≥ 两者种子 SD 的较大值。
- **V2 河道**：学到的入口空间滤波与同被试 CSP 滤波可匹配——top-4 滤波中 ≥ 2 个最佳匹配 |cos| ≥ 0.7，且滤波地形图出现 C3/C4/Cz 侧化；随机湖与打乱标签训练的湖都不出现该模式。
- **V3 持平**：κ 与同协议 FBCSP（被试内）、EA+TS+LR（LOSO）的差距 ≤ 0.05。
- **V4 在线**：S5 的连续运行解码器在 E 会话上经在线更新后，比静态 T 训练模型高 ≥ 0.05。

### 0.3 失败条件（任一成立即结项，写机制性负结果）

- **F1**：S1 玩具不可学——换了神经元模型，证书下的 EP 仍学不出两通道乘积或加窗方差。
- **F2**：S3 基底判定失败——同一架构用隐式梯度或 BPTT 训练也不超过随机湖。
- **F3**：S3 的 V1 成立但 V2 不成立，且 S4 扩到 ≥ 60 名被试后仍不成立。

## S0 工具链（预注册）

### S0.1 问题

能否在 cadence fork 上加入光滑偶分量神经元、级联证书（默认）、torch 后端、跨时间位置的权重绑定、以及不经激活的输入群体，并且：(i) EP 更新在新神经元上仍与隐式梯度一致；(ii) 新证书没有假阳性；(iii) 吞吐足以支撑 S3 的预算。S0 不使用任何 EEG 数据。

### S0.2 工作项

**W1 偶分量神经元。** ρ(v) = a·tanh(v/2) + b·tanh²(v/2)，a > 0，b 实数；a、b 按群体配置（每个神经元一对参数，同一群体取同值）。ρ(0) = 0，静息仍发放 0；ρ 光滑（C^∞），在 0 处无折点。a = 1、b = 0 时与现行 `learning_neuron_model(leak=1.0)` 的 tanh(v/2) 完全相同。

- 记 t = tanh(v/2) ∈ (−1, 1)。ρ = a t + b t²。b ≥ 0 时值域上界为 a + b，下界在 a < 2b 时为 −a²/(4b)，否则为 −(a − b)；b < 0 时由 ρ(v; a, −b) = −ρ(−v; a, b) 镜像得到。
- 导数：ρ′(v) = ½ (1 − t²)(a + 2 b t)。
- **Lipschitz 常数**（写进证书）：L(a, b) = sup_v |ρ′(v)| = ½ · max_{t ∈ (−1,1)} |g(t)|，g(t) = (1 − t²)(a + 2bt)。端点处 g = 0，所以极值在 g′(t) = 2b − 2at − 6bt² = 0 的根上：
  - b = 0：L = a/2。
  - b ≠ 0：t± = (−a ± √(a² + 12 b²)) / (6 b)，L = ½ · max{ |g(t)| : t ∈ {t+, t−} ∩ (−1, 1) }。两根之积为 −1/3，至少一个根落在 (−1, 1) 内。L 只依赖 |b|（t → −t 对称）。
  - 例：L(1, 0) = 0.5；L(1, 0.25) = 0.52815；L(1, 0.5) = 0.59259（= 16/27）；L(1, 1) = 0.75808；L(0, 1) = 2/(3√3) = 0.38490。（已用 v ∈ [−40, 40] 上 2×10⁶ 点的稠密网格核对到 1e-10，这是推导核对，不是实验。）
- b > a/2 时 ρ 非单调，ρ′ 在 t = −a/(2b) 处为 0。EP 的推导只需要平衡点关于 β 可微（压缩证书保证 I − W·diag(ρ′) 可逆），不需要 ρ 单调；但这一点要由 D1 的复跑来确认，所以 D1 同时包含单调与非单调两种 (a, b)。
- 现行 cadence 的激活是重定标 sigmoid（`slope`、`threshold`、`leak`），只有一个全局 `NeuronModel`。新增激活族与每神经元参数是 fork 改动，见 S0.7。

**W2 级联证书（ADR-0012）为默认。** 输入群体没有入边；行质量只计 free→free 边；按群体 Lipschitz 常数加权：

  ρ̃_free = max_{i ∈ free} Σ_{j ∈ free} |W_ij| · L_j，q_f = 1 − dt·(1 − ρ̃_free)，certified ⟺ ρ̃_free < 1 且无 adaptation，

  全系统渐近速率 max(q_f, 1 − dt)。所有 L_j 相同时退化为 ADR-0012 的 L·ρ_free。行质量投影只缩放 free→free 边；输入突触幅度自由。

**W3 torch 后端。** cadence 已有 `backend="torch"`（`_TorchKernel`，float64 或 `precision="float32"`）。S0 把新激活和每神经元参数接进它；本机只有 torch CPU。参考实现为 CPU numpy float64（可选 numba `[fast]`）。若 S0.4 的吞吐不足，按指令 §3 允许在本仓库写独立的 torch 静态 EP 实现（`ep_eeg/m12_torch_ep.py`），同样以 D1 等价检验准入。

**W4 `tie_groups` 跨时间位置。** 入口权重按（空间滤波 k，输入分量 c）成组，跨 T 个时间位置共享一个效能（时间平移不变）。cadence `Learner(tie_groups=...)` 已存在（组内按成员对比量的**均值**更新）；S0 加构造工具、组内初值相等的校验，以及均值与 IFT「组内求和」梯度之间的步长换算（见 S0.7）。

**W5 输入群体不经激活。** 输入神经元的发放直接等于钳制值（s_in = x，常数驱动，不过 ρ），不计入行质量、幅度自由，避免 M9c 的入口饱和。cadence 现在没有逐神经元的激活选择；实现为每神经元「线性」标志（见 S0.7）。

### S0.3 验收检验（判据，预注册）

**准入检查（每项 fork 改动进入正式检验前；不属于 G0 三条，但不过则不跑对应检验）**

- **回归**：a = 1、b = 0、输入经激活时，新代码与旧路径（`learning_neuron_model(leak=1.0)`）在 M11 D1 的小图上逐元素一致：平衡态与 EP 对比量的最大绝对差 ≤ 1e-12（CPU float64）。M11 D1 的 leak=1.0 生产格子用新代码复算，cos(EP, IFT) 与 M11 回执之差 ≤ 1e-9。

- **绑定检查（D1-T）**：小图改成 2 个时间位置 × 3 个输入分量、隐层 2 × 5，源→隐层边跨位置绑定；任意次更新后组内效能最大差 ≤ 1e-12；EP 对共享参数的估计与 IFT 的组内求和梯度（换算步长后）满足与 A1 相同的两条阈值。24 格（3 行质量 × 2 输入幅度 × 2 nudge × 种子 0/1/2，(a, b) = (1, 1)）。

**A1 D1 等价检验（72 格，在新神经元上复跑）**

- 图与 M11 D1（`ep_eeg/m11_d1.py`）相同：6 个源 → 10 个隐层（单向），隐层全互惠，隐层 ↔ 3 输出互惠；16 个随机输入；度量、物理坐标与边类别（deep、lateral、readout、bias）不变。改动只有三处：源神经元**不经激活**（W5）；行质量按 W2 的加权级联计法缩放到预算；M11 的 leak 轴换成神经元轴。
- **72 格** = 神经元 {N1: (a, b) = (1, 0.25)，单调；N2: (a, b) = (1, 1)，非单调} × 行质量预算 ρ̃_free ∈ {0.3, 0.6, 0.9} × 输入幅度 {0.5, 4} × nudge {CE（T = 0.1）, 二次} × 种子 {0, 1, 2}。每格同时算完整的 β × 容限网格（β ∈ {0.1, 0.04, 0.01, 0.0025}，容限 ∈ {3e-3, 1e-4, 1e-6, 1e-9}），只用于报告边界。
- 计算顺序（沿用 M11 修改 1 的 M1-11）：先只跑 IFT 对 FD 并提交回执，再跑 EP 对 IFT。IFT 与 FD 都在 1e-11 的紧平衡点上算；FD 为中心差分 h = 1e-4。余弦在批平均梯度上算。
- **有效性前提**：每格 cos(IFT, FD) ≥ **0.99999**（全部参数，且每个边类别）。不满足的格子记「无效」并先修实现，不记「不成立」。
- **判据 A1**：生产设置（β = 0.04、容限 3e-3、中心化 ±β）下，每格 cos(EP, IFT) 的 **3 种子最小值 ≥ 0.999**，对全部参数和 deep 类各自成立。72 格全部满足 → A1 成立。
- **后端**：A1 与有效性前提在 **CPU numpy float64** 和 **torch CPU float64** 两个后端上都必须成立（判据）。**torch CPU float32** 跑同一组 72 格，记录 cos(EP, IFT)、cos(EP_f32, EP_f64)、平衡残差和拒相数，作描述，不判；FD 只在 float64 上算。回执写明每个后端的 dtype 与设备。
- **无 GPU**：CUDA/MPS 后端在本机不能运行，A1 在它们上面的成立与否标「未测」。

**A2 证书无假阳性（≥ 1000 个随机配置）**

- 生成器（种子固定，配置逐个写回执）：源数 ∈ {0, 6, 64}，自由神经元数 ∈ {8, 32, 128, 256}，free→free 密度 ∈ {0.1, 0.5, 1.0}，对称与非对称各半（证书本身不要求对称）；每个群体的 (a, b) 取 a ∈ U[0.2, 2]、b ∈ U[−2, 2]；dt ∈ {0.2, 0.5, 1.0}；ρ̃_free 目标值 70% 取 U(0, 0.95)，30% 取 U[0.95, 0.999)（贴边）；输入幅度 ∈ {0.5, 4, 16}；偏置 N(0, 1)；batch 8。一直生成直到 **certified 的配置 ≥ 1000 个**；另生成 ≥ 200 个 ρ̃_free ∈ (1, 1.5] 的未认证配置，只作描述。
- 每个配置在 `equilibrate` 下从两个起点求解：静息（v = 0）和随机大初值（v ~ N(0, 25)），步数上限 10⁶。
- **假阳性** = certified 且（任一起点在 10⁶ 步内未达残差 ≤ 1e-9，或两起点平衡态的最大差 > 1e-6）。
- 另报（描述，不判）：「速率越界」= 达到残差所用步数超过 4 × ⌈log(1e-10 · (1 − q)/Δ₀) / log q⌉ + ⌈log(1e-10)/log(1 − dt)⌉（Δ₀ 为首步位移；后一项为源暂态）的配置数。级联速率是渐近速率，不给单步界，所以它不进判据。
- **判据 A2**：假阳性数 = **0**。CPU float64 判定；torch CPU float64 在同一批配置上复算，同样要求 0。

**A3 吞吐基准**

- 图：1760 个输入神经元（不经激活）单向全连到 H = 512 个自由隐层神经元（N2: a = 1、b = 1），隐层全互惠，隐层 ↔ 4 个输出互惠；ρ̃_free = 0.9；输入 N(0, 1)；batch 64；容限 3e-3（生产值），`qualified=True`，静息冷启动。
- 计量：一次 qualified 自由相平衡的墙钟 t_free；随后 ±β 两个微扰相（从自由态热启动）t_+、t_−；一次 EP 更新 t_u = t_free + t_+ + t_− + t_contrast；同时报步数、残差、合格率。另报一次 IFT 更新（1e-11 紧平衡 + 伴随线性求解）的墙钟 t_IFT。3 次预热后取 20 次的中位数与 IQR。
- 后端 × 线程配置：CPU numpy float64（`[fast]`）、torch CPU float64、torch CPU float32；每个后端在 (8 线程 × 1 作业) 与 (2 线程 × 4 并发作业，测并发下每作业的 t_u) 两种配置下各测一次。
- **GPU 数字**：指令要求 GPU 与 CPU 各报一个数。**本机无 GPU，GPU 数字不能在这里测，S0 只报 CPU 与 CPU torch。** 这是 G0 必须由人处理的一项（§6「需要新算力」）。
- 次要（不进判据、不进 U）：S3 架构草案（入口 K = 8 个空间滤波 × 80 个时间位置、每个入口神经元读 22 个分量、跨时间绑定；K 个汇聚；4 个 motor）的同口径 t_u，供 S3 预注册参考。
- **判据 A3**：基准完成，所有数字有限并写进回执，且由下式算出的 U ≥ U_min（见下）。

**U 的换算（写死；数值在 G0 时代入并写进 S3 预注册）**

  U = ⌊ f · W_S3 · P / ( t_u · R · (Σ_a c_a + 2·c_EP) ) ⌋

- W_S3 = 6 周 = 3 628 800 s（S3 墙钟上限）；f = 0.6（其余 40% 留给闭式基线、ridge/sLDA 读出、FBCSP/EEGNet/EA+TS+LR、验证器与 crash 重跑）。
- P = 并发作业数，t_u 取 **该并发配置下实测的** 每作业 t_u（A3 中 2 线程 × 4 作业那一行，P = 4；若 8 线程 × 1 作业的总吞吐更高，则取 P = 1 和那一行，取两者中 U 较大者）。基准后端取 A1 与 A2 都通过的后端中最快的一个。
- R = 每个迭代训练 arm 的运行数 = 9 名被试 × 3 种子 × n_prot，n_prot ∈ {1, 2}（S2 决定 S3 以 LOSO 为主时 n_prot = 1 指 LOSO；并列时 n_prot = 2）。G0 时按 n_prot = 2 计算（保守），S2 之后若为 1，在 S3 预注册中重算并写明。
- 迭代训练 arm 及相对代价 c_a：EP 训练湖（其 EP 读出取自同一运行）c = 1；打乱标签 EP 湖 c = 1；无横向消融 EP 湖 c = 1（上界）；IFT 训练同架构 c_IFT = t_IFT / t_u（A3 实测）。随机湖不训练，c = 0。
- 「+ 2·c_EP」是 G3 停止规则里「一轮优化修，U × 2」的预留：只给 EP 训练湖那一条 arm 留 2U 的余量。
- 用 U 换算 epoch：被试内每 epoch 192 × 9 窗 / 64 = 27 次更新；LOSO 每 epoch 8 × 288 × 9 / 64 = 324 次更新。
- **U_min = 2 700**（被试内 100 epoch；M6、M9 的常用 epoch 数）。U < U_min 即「吞吐不足以支撑 S3 预算」。
- 示意（假设值，不是结果）：P = 4、n_prot = 2、c_IFT = 1 时 U ≈ 0.6 · 3 628 800 · 4 / (t_u · 54 · 6) ≈ 26 880 / t_u（t_u 以秒计）。

### S0.5 停止规则

1. 2 天墙钟用完而判据未出：按现有回执结项 S0，未出的判据标「检验力不足」，交 G0。
2. 有效性前提（IFT 对 FD）或准入检查不过：是实现错误，修实现后重跑该检验；不改判据，不算 A1 不成立。修实现的时间计入 2 天上限。
3. A1 在有效格子上不满足：不改 β、容限或阈值；记录不满足的格子与边界，交 G0。人可批准一轮修（如改 (a, b) 的取值范围、β、容限），修后的判定标 post-hoc。
4. A2 出现任一假阳性：立即停止该扫描，保留反例回执；这是证书推导或实现的错误，A2 记不成立，交 G0。
5. A3 的 U < U_min，或 GPU 数字缺失：交 G0，由人决定加算力（GPU）、缩 H，或接受 CPU 预算。
6. 任何时候：不读 E；后台运行按 PID 跟踪；回执逐运行写出，可从检查点恢复。

### S0.6 门槛 G0

G0 = A1、A2、A3 三条全过。G0 的判定一出即交人（§6 必须找人的时刻 1），附判定表、≤ 3 个选项与各自算力代价。本机无 GPU，A3 的 GPU 数字必然缺失，所以 **G0 无论如何都要人就算力作决定**：选项预计为 (a) 接受 CPU 吞吐与对应的 U；(b) 提供 GPU 后补测 A1 的 CUDA 后端与 A3 的 GPU 数字；(c) 缩 H。

### S0.8 与仓库事实的冲突（提交前写明，交人或冷读裁定）

1. **ADR-0005（已接受）禁止 EA 及一切跨导联空间变换**；指令把 EA 定为物理先验，S2–S5 都依赖它。修改已接受的 ADR 是 §6 的必须找人时刻 4。草拟的 ADR-0013（proposed）提出在 M12 中取代 ADR-0005 的这一条，须人接受后 S2 才能运行。
2. **ADR-0002（已接受）的垂直锚定**（一个导联只注入其下方微柱）与指令「入口允许全混合」冲突；ADR-0013 同样提出在 M12 中取代。
3. **ADR-0012 的适用范围**写的是「只用于 M9c 的最终实验」；指令要求级联证书为 M12 默认。ADR-0013 提出扩展范围，并加 Lipschitz 加权。
4. **AGENTS.md**：「cadence 只读」「修改 cadence 源码写入待决问题」「预处理层做 tanh(x/3) 压缩」「零结构先验」与指令 §3（cadence 可改、输入不经激活、改为零解剖先验 + 物理先验）冲突。指令是人的最新决定，按指令执行；AGENTS.md 的对应条目留待人确认后改写，本次不改。
5. **基线标签**：指令 §2 写「EA+TS+LR 0.512（被试内）」。M11 A 的 0.512 是 `A_tslr`（OAS 协方差 → 切空间 → LR），**没有做 EA**。被试内 V3 的参照仍按指令用 FBCSP；LOSO 的 EA+TS+LR 数字目前不存在，由 S2 产出。
6. **D1 的 72 格**：M11 的 72 格 = 3 种子 × leak {1.0, 0.1} × 3 行质量 × 2 输入幅度 × 2 nudge。leak = 0.1 有折点，指令禁止；本节把 leak 轴换成两个 (a, b)，格数不变。M11 判据是在生产 β/容限下判的；本节同样只在生产设置下判，β=0.0025 配容限 3e-3 在 M11 已知会给出零对比，所以网格不进判据。
7. **吞吐基准的形状**：指令写 H = 512、输入 1760；S3 的入口架构是 K × 80 = 640 个绑定的入口神经元，每个只读 22 维，比 H = 512 的全连接轻得多。按指令用 H = 512 换算 U（偏保守），S3 架构只作次要计量。
8. **S0 时长**：指令 §4 说 S0「1–2 周」，§6 说 S0 算力上限「2 天墙钟」。本节理解为开发 1–2 周、验收运行的算力墙钟 2 天。
9. **GPU**：指令以 torch（CUDA/MPS）为主后端，并要求 GPU 吞吐；本机无 GPU（见 0.7、S0.6）。
10. AGENTS.md「环境」写容器重启后为 4 CPU；当前实测 8 核。
