# M12 双湖 v2：在三个条件同时满足时检验河道假设（预注册）

状态：**预注册**，写于 2026-10-19。分支 `M12`，从 `m11`（`48321ab`）分出。指令原文：人于 2026-10-19 给出的《M12 双湖 v2：Scale 到底的执行指令》（下称「指令」）。本文件第一次提交时，M12 还没有运行任何实验：没有改 cadence、没有训练、没有评估、没有读取任何 M12 指标。提交之后对已提交预注册内容的任何改动，都写进文末的「事后修改」节，并标明时间、原因，以及改动前是否已看到相关结果。

## 0. 总述

### 0.1 问题

在带收敛证书、只用局部学习的 EP 湖上，当**输入**（原始窗 + 时间平移共享）、**非线性**（光滑偶分量神经元）、**样本量**（EA 跨被试合并）三个条件同时满足时，湖能否从原始 EEG 自己冲刷出跨导联的功率/协方差结构（河道），并在准确率上与 FBCSP、EA+TS+LR 持平。M0–M11 从未同时满足这三个条件。

「走到底」：三个条件逐一补齐后，在 ≥ 2 个数据集、≥ 60 名被试上得到明确的是或否。

### 0.2 胜利条件（全部满足才算成立）

- **V1 表征**：EP 训练湖 + ridge 在 2a 被试内 ≥ 7/9、LOSO ≥ 7/9 留出被试上超过同配置随机湖 + ridge，边际 ≥ 两者种子 SD 的较大值。
- **V2 河道**：学到的入口空间滤波与同被试 CSP 滤波可匹配——top-4 滤波中 ≥ 2 个最佳匹配 |cos| ≥ 0.7，且滤波地形图出现 C3/C4/Cz 侧化；随机湖与打乱标签训练的湖都不出现该模式。
- **V3 持平**：κ 与同协议 FBCSP（被试内）、EA+TS+LR（LOSO）的差距 ≤ 0.05。
- **V4 在线**：S5 的连续运行解码器在 E 会话上经在线更新后，比静态 T 训练模型高 ≥ 0.05。

### 0.3 失败条件（任一成立即结项，写机制性负结果）

- **F1**：S1 玩具不可学——换了神经元模型，证书下的 EP 仍学不出两通道乘积或加窗方差。
- **F2**：S3 基底判定失败——同一架构用隐式梯度或 BPTT 训练也不超过随机湖。
- **F3**：S3 的 V1 成立但 V2 不成立，且 S4 扩到 ≥ 60 名被试后仍不成立。

## S0 工具链（预注册）

### S0.1 问题

能否在 cadence fork 上加入光滑偶分量神经元、级联证书（默认）、torch 后端、跨时间位置的权重绑定、以及不经激活的输入群体，并且：(i) EP 更新在新神经元上仍与隐式梯度一致；(ii) 新证书没有假阳性；(iii) 吞吐足以支撑 S3 的预算。S0 不使用任何 EEG 数据。

### S0.2 工作项

**W1 偶分量神经元。** ρ(v) = a·tanh(v/2) + b·tanh²(v/2)，a > 0，b 实数；a、b 按群体配置（每个神经元一对参数，同一群体取同值）。ρ(0) = 0，静息仍发放 0；ρ 光滑（C^∞），在 0 处无折点。a = 1、b = 0 时与现行 `learning_neuron_model(leak=1.0)` 的 tanh(v/2) 完全相同。

- 记 t = tanh(v/2) ∈ (−1, 1)。ρ = a t + b t²。b ≥ 0 时值域上界为 a + b，下界在 a < 2b 时为 −a²/(4b)，否则为 −(a − b)；b < 0 时由 ρ(v; a, −b) = −ρ(−v; a, b) 镜像得到。
- 导数：ρ′(v) = ½ (1 − t²)(a + 2 b t)。
- **Lipschitz 常数**（写进证书）：L(a, b) = sup_v |ρ′(v)| = ½ · max_{t ∈ (−1,1)} |g(t)|，g(t) = (1 − t²)(a + 2bt)。端点处 g = 0，所以极值在 g′(t) = 2b − 2at − 6bt² = 0 的根上：
  - b = 0：L = a/2。
  - b ≠ 0：t± = (−a ± √(a² + 12 b²)) / (6 b)，L = ½ · max{ |g(t)| : t ∈ {t+, t−} ∩ (−1, 1) }。两根之积为 −1/3，至少一个根落在 (−1, 1) 内。L 只依赖 |b|（t → −t 对称）。
  - 例：L(1, 0) = 0.5；L(1, 0.25) = 0.52815；L(1, 0.5) = 0.59259（= 16/27）；L(1, 1) = 0.75808；L(0, 1) = 2/(3√3) = 0.38490。（已用 v ∈ [−40, 40] 上 2×10⁶ 点的稠密网格核对到 1e-10，这是推导核对，不是实验。）
- b > a/2 时 ρ 非单调，ρ′ 在 t = −a/(2b) 处为 0。EP 的推导只需要平衡点关于 β 可微（压缩证书保证 I − W·diag(ρ′) 可逆），不需要 ρ 单调；但这一点要由 D1 的复跑来确认，所以 D1 同时包含单调与非单调两种 (a, b)。
- 现行 cadence 的激活是重定标 sigmoid（`slope`、`threshold`、`leak`），只有一个全局 `NeuronModel`。新增激活族与每神经元参数是 fork 改动，见 S0.7。

**W2 级联证书（ADR-0012）为默认。** 输入群体没有入边；行质量只计 free→free 边；按群体 Lipschitz 常数加权：

  ρ̃_free = max_{i ∈ free} Σ_{j ∈ free} |W_ij| · L_j，q_f = 1 − dt·(1 − ρ̃_free)，certified ⟺ ρ̃_free < 1 且无 adaptation，

  全系统渐近速率 max(q_f, 1 − dt)。所有 L_j 相同时退化为 ADR-0012 的 L·ρ_free。行质量投影只缩放 free→free 边；输入突触幅度自由。

**W3 torch 后端。** cadence 已有 `backend="torch"`（`_TorchKernel`，float64 或 `precision="float32"`）。S0 把新激活和每神经元参数接进它；本机只有 torch CPU。参考实现为 CPU numpy float64（可选 numba `[fast]`）。若 S0.4 的吞吐不足，按指令 §3 允许在本仓库写独立的 torch 静态 EP 实现（`ep_eeg/m12_torch_ep.py`），同样以 D1 等价检验准入。

**W4 `tie_groups` 跨时间位置。** 入口权重按（空间滤波 k，输入分量 c）成组，跨 T 个时间位置共享一个效能（时间平移不变）。cadence `Learner(tie_groups=...)` 已存在（组内按成员对比量的**均值**更新）；S0 加构造工具、组内初值相等的校验，以及均值与 IFT「组内求和」梯度之间的步长换算（见 S0.7）。

**W5 输入群体不经激活。** 输入神经元的发放直接等于钳制值（s_in = x，常数驱动，不过 ρ），不计入行质量、幅度自由，避免 M9c 的入口饱和。cadence 现在没有逐神经元的激活选择；实现为每神经元「线性」标志（见 S0.7）。

### S0.3 验收检验（判据，预注册）

**准入检查（每项 fork 改动进入正式检验前；不属于 G0 三条，但不过则不跑对应检验）**

- **回归**：a = 1、b = 0、输入经激活时，新代码与旧路径（`learning_neuron_model(leak=1.0)`）在 M11 D1 的小图上逐元素一致：平衡态与 EP 对比量的最大绝对差 ≤ 1e-12（CPU float64）。M11 D1 的 leak=1.0 生产格子用新代码复算，cos(EP, IFT) 与 M11 回执之差 ≤ 1e-9。

**A1 D1 等价检验（72 格，在新神经元上复跑）**

- 图与 M11 D1（`ep_eeg/m11_d1.py`）相同：6 个源 → 10 个隐层（单向），隐层全互惠，隐层 ↔ 3 输出互惠；16 个随机输入；度量、物理坐标与边类别（deep、lateral、readout、bias）不变。改动只有三处：源神经元**不经激活**（W5）；行质量按 W2 的加权级联计法缩放到预算；M11 的 leak 轴换成神经元轴。
- **72 格** = 神经元 {N1: (a, b) = (1, 0.25)，单调；N2: (a, b) = (1, 1)，非单调} × 行质量预算 ρ̃_free ∈ {0.3, 0.6, 0.9} × 输入幅度 {0.5, 4} × nudge {CE（T = 0.1）, 二次} × 种子 {0, 1, 2}。每格同时算完整的 β × 容限网格（β ∈ {0.1, 0.04, 0.01, 0.0025}，容限 ∈ {3e-3, 1e-4, 1e-6, 1e-9}），只用于报告边界。
- 计算顺序（沿用 M11 修改 1 的 M1-11）：先只跑 IFT 对 FD 并提交回执，再跑 EP 对 IFT。IFT 与 FD 都在 1e-11 的紧平衡点上算；FD 为中心差分 h = 1e-4。余弦在批平均梯度上算。
- **有效性前提**：每格 cos(IFT, FD) ≥ **0.99999**（全部参数，且每个边类别）。不满足的格子记「无效」并先修实现，不记「不成立」。
- **判据 A1**：生产设置（β = 0.04、容限 3e-3、中心化 ±β）下，每格 cos(EP, IFT) 的 **3 种子最小值 ≥ 0.999**，对全部参数和 deep 类各自成立。72 格全部满足 → A1 成立。
- **后端**：A1 与有效性前提在 **CPU numpy float64** 和 **torch CPU float64** 两个后端上都必须成立（判据）。**torch CPU float32** 跑同一组 72 格，记录 cos(EP, IFT)、cos(EP_f32, EP_f64)、平衡残差和拒相数，作描述，不判；FD 只在 float64 上算。回执写明每个后端的 dtype 与设备。
- **无 GPU**：CUDA/MPS 后端在本机不能运行，A1 在它们上面的成立与否标「未测」。

**A2 证书无假阳性（≥ 1000 个随机配置）**

- 生成器（种子固定，配置逐个写回执）：源数 ∈ {0, 6, 64}，自由神经元数 ∈ {8, 32, 128, 256}，free→free 密度 ∈ {0.1, 0.5, 1.0}，对称与非对称各半（证书本身不要求对称）；每个群体的 (a, b) 取 a ∈ U[0.2, 2]、b ∈ U[−2, 2]；dt ∈ {0.2, 0.5, 1.0}；ρ̃_free 目标值 70% 取 U(0, 0.95)，30% 取 U[0.95, 0.999)（贴边）；输入幅度 ∈ {0.5, 4, 16}；偏置 N(0, 1)；batch 8。一直生成直到 **certified 的配置 ≥ 1000 个**；另生成 ≥ 200 个 ρ̃_free ∈ (1, 1.5] 的未认证配置，只作描述。
- 每个配置在 `equilibrate` 下从两个起点求解：静息（v = 0）和随机大初值（v ~ N(0, 25)），步数上限 10⁶。
- **假阳性** = certified 且（任一起点在 10⁶ 步内未达残差 ≤ 1e-9，或两起点平衡态的最大差 > 1e-6）。
- 另报（描述，不判）：「速率越界」= 达到残差所用步数超过 4 × ⌈log(1e-10 · (1 − q)/Δ₀) / log q⌉ + ⌈log(1e-10)/log(1 − dt)⌉（Δ₀ 为首步位移；后一项为源暂态）的配置数。级联速率是渐近速率，不给单步界，所以它不进判据。
- **判据 A2**：假阳性数 = **0**。CPU float64 判定；torch CPU float64 在同一批配置上复算，同样要求 0。

**A3 吞吐基准**

- 图：1760 个输入神经元（不经激活）单向全连到 H = 512 个自由隐层神经元（N2: a = 1、b = 1），隐层全互惠，隐层 ↔ 4 个输出互惠；ρ̃_free = 0.9；输入 N(0, 1)；batch 64；容限 3e-3（生产值），`qualified=True`，静息冷启动。
- 计量：一次 qualified 自由相平衡的墙钟 t_free；随后 ±β 两个微扰相（从自由态热启动）t_+、t_−；一次 EP 更新 t_u = t_free + t_+ + t_− + t_contrast；同时报步数、残差、合格率。另报一次 IFT 更新（1e-11 紧平衡 + 伴随线性求解）的墙钟 t_IFT。3 次预热后取 20 次的中位数与 IQR。
- 后端 × 线程配置：CPU numpy float64（`[fast]`）、torch CPU float64、torch CPU float32；每个后端在 (8 线程 × 1 作业) 与 (2 线程 × 4 并发作业，测并发下每作业的 t_u) 两种配置下各测一次。
- **GPU 数字**：指令要求 GPU 与 CPU 各报一个数。**本机无 GPU，GPU 数字不能在这里测，S0 只报 CPU 与 CPU torch。** 这是 G0 必须由人处理的一项（§6「需要新算力」）。
- 次要（不进判据、不进 U）：S3 架构草案（入口 K = 8 个空间滤波 × 80 个时间位置、每个入口神经元读 22 个分量、跨时间绑定；K 个汇聚；4 个 motor）的同口径 t_u，供 S3 预注册参考。
- **判据 A3**：基准完成，所有数字有限并写进回执，且由下式算出的 U ≥ U_min（见下）。

**U 的换算（写死；数值在 G0 时代入并写进 S3 预注册）**

  U = ⌊ f · W_S3 · P / ( t_u · R · (Σ_a c_a + 2·c_EP) ) ⌋

- W_S3 = 6 周 = 3 628 800 s（S3 墙钟上限）；f = 0.6（其余 40% 留给闭式基线、ridge/sLDA 读出、FBCSP/EEGNet/EA+TS+LR、验证器与 crash 重跑）。
- P = 并发作业数，t_u 取 **该并发配置下实测的** 每作业 t_u（A3 中 2 线程 × 4 作业那一行，P = 4；若 8 线程 × 1 作业的总吞吐更高，则取 P = 1 和那一行，取两者中 U 较大者）。基准后端取 A1 与 A2 都通过的后端中最快的一个。
- R = 每个迭代训练 arm 的运行数 = 9 名被试 × 3 种子 × n_prot，n_prot ∈ {1, 2}（S2 决定 S3 以 LOSO 为主时 n_prot = 1 指 LOSO；并列时 n_prot = 2）。G0 时按 n_prot = 2 计算（保守），S2 之后若为 1，在 S3 预注册中重算并写明。
- 迭代训练 arm 及相对代价 c_a：EP 训练湖（其 EP 读出取自同一运行）c = 1；打乱标签 EP 湖 c = 1；无横向消融 EP 湖 c = 1（上界）；IFT 训练同架构 c_IFT = t_IFT / t_u（A3 实测）。随机湖不训练，c = 0。
- 「+ 2·c_EP」是 G3 停止规则里「一轮优化修，U × 2」的预留：只给 EP 训练湖那一条 arm 留 2U 的余量。
- 用 U 换算 epoch：被试内每 epoch 192 × 9 窗 / 64 = 27 次更新；LOSO 每 epoch 8 × 288 × 9 / 64 = 324 次更新。
- **U_min = 2 700**（被试内 100 epoch；M6、M9 的常用 epoch 数）。U < U_min 即「吞吐不足以支撑 S3 预算」。
- 示意（假设值，不是结果）：P = 4、n_prot = 2、c_IFT = 1 时 U ≈ 0.6 · 3 628 800 · 4 / (t_u · 54 · 6) ≈ 26 880 / t_u（t_u 以秒计）。

- **评估自由相**：用 qualified 的 `equilibrate`，容限 3e-3、damping 3、静息冷启动。未收敛的行计入拒行，并与每个准确率一起报告（声明规则）。
- **ridge 读出**：
  - 特征：全部非输出自由神经元在自由平衡态下的发放，用训练集的统计量标准化。
  - 模型：T1 用 `sklearn.linear_model.Ridge`，T2 用 `RidgeClassifier`。
  - α 从 `logspace(-3, 4, 15)` 中选（M11 B 的网格），只在训练集上做 5 折交叉验证。
- **种子**：正式运行用种子 0、1、2，每个配置 3 个种子。初值种子 = seed，数据种子 = 1000 + seed，批次种子 = 2000 + seed。
  - 开发运行只用种子 ≥ 100 和 (a, b) = (1, 0.6)（不在正式网格里）。回执标 `dev=true`，保存在 `receipts/M12/S1/dev/`（沿用修改 1 N10）。
  - 种子 0–2 的数据和初值，在冷读意见落实之前不运行。
- **回执**：每个运行一个 JSON，路径为 `receipts/M12/S1/<commit>/<task>/<arm>/<neuron>_<H或K>_s<seed>.json`。内容包括：
  - 修改 1 N7 的全部字段；

### 〔作废〕 S1.3 T1 两通道乘积

- **数据**：x = (x1, x2) ~ N(0, I₂)，训练 4 096 个、测试 4 096 个，两者独立生成。目标 t = 0.5 + 0.25·x1·x2。
  - 采用仿射映射，是为了让目标落进输出神经元的值域：N1 为 (−0.75, 1.25)，N2 为 (−0.25, 2)。R² 不受这个仿射映射影响。
  - 推导核对（不是实验）：x1·x2 超出可达区间的概率约为 1.0–1.1%（N1 的可达区间是 x1x2 ∈ (−5, 3)，N2 是 (−3, 6)）。即使输出完全饱和在边界上，R² 的上限也在 0.98 以上，高于 0.9 的判据，所以判据可以满足。
- **架构**（与 D1 std 同构）：
  - 2 个线性源单向连到 H 个隐层神经元，W_in ~ N(0, 1)；
  - 隐层之间全互惠，初值 N(0, 1)；隐层与 1 个输出神经元互惠，初值 N(0, 1)；
  - 偏置 0；free→free 缩放到 ρ̃ = 0.6；
  - H ∈ {8, 32}，按指令。
- **arm**：EP 训练湖、随机湖 + ridge、IFT 训练湖（T3）。每个 arm 都覆盖 2 个神经元 × 2 个 H × 3 个种子。
- **度量**：
  - R²_out：EP 训练湖输出神经元的测试 R² = 1 − SSE/SST，在 t 的尺度上计算；
  - R²_ridge(训练湖)：只作描述；
  - R²_ridge(随机湖)。

### 〔作废〕 S1.4 T2 加窗方差（CSP 等价）

- **数据**：
  - 每个试次有 6 个隐源 z ∈ R^{6×64}，每个样本独立取 N(0, 1)。z₀ 是源 A，z₁ 是源 B，z₂–z₅ 是功率恒定的背景源。
  - 类别 0：z₀ 乘 √0.5，即源 A 功率降 50%。类别 1：z₁ 乘 √0.5，即源 B 功率降 50%。
  - 通道信号 X = M z，M ∈ R^{6×6}，元素取 N(0, 1/6)，按数据种子抽取；若 cond(M) > 10 就重抽，并在回执里记下抽取次数。
  - 训练 4 096 个试次、测试 4 096 个试次，两类各半。
  - 输入是 6 × 64 展平成的 384 个线性源，源 (p, c) 的编号为 p·6 + c（`time_shared_entry` 的约定）。
  - 真解混向量 u_A、u_B 是 M⁻¹ 的第 0 行和第 1 行。
- **架构**（S3 草案的缩小版）：
  - `time_shared_entry(6, 64, K)`，K = 4。入口神经元 (k, p) 只读位置 p 的 6 个通道；W[k, :] 跨 64 个位置绑定，初值共享，取 N(0, 1/6)。`synapse_rate = tie_rates(groups)`（修改 1 B4）。
  - 4 个汇聚神经元：入口 (k, ·) 与汇聚神经元 k 互惠，初值在各位置上取相等的正值，即按时间求和初始化（指令 S3），可塑。
  - 入口层内部全互惠，初值 N(0, 1/256)；汇聚层内部全互惠，初值 N(0, 1/4)；汇聚层与 2 个输出神经元互惠，初值 N(0, 1/4)。
  - 偏置 0；free→free 统一缩放到 ρ̃ = 0.6。
- **oracle**：每个试次在窗内算真源 z₀、z₁ 的对数方差（按类别缩放之后，混合之前），得到 2 个特征。用 `LinearDiscriminantAnalysis()` 在训练集上拟合，在测试集上算 κ_oracle。
- **arm**：EP 训练湖 + ridge、随机湖 + ridge（只作描述）、IFT 训练湖 + ridge（T3）。每个 arm 都覆盖 2 个神经元 × 3 个种子。另外报告 EP 的输出读出 κ，只作描述。
- **度量**：
  - κ（`cohen_kappa_score`，测试集）与准确率；
  - 入口滤波 W_k：组 (k, c) 的有效权重组成的 6 维向量；
  - match(u) = max_k |cos(W_k, u)|，对 u_A、u_B 各算一次。

### 〔作废〕 S1.8 停止规则

1. **超时**：1 周墙钟用完而判据未出，按现有回执结项 S1，未出的判据标「检验力不足」，交 G1。
2. **实现错误**：以下任一情形都按实现错误处理：证书在初始化时、投影后或 epoch 末不过；出现非有限值；E 封存核对失败；准入检查不过。处理方式是停止该运行、修实现，然后该运行从头重跑。判据不改，修实现的时间计入 1 周上限。
3. **拒相**：按 S1.2 处理，接受率 < 0.98 的运行记为不满足。
4. **更新次数固定**：每个运行都做满 19 200 次更新，不早停，不按结果加跑 epoch。
5. **G1 交人**：G1 的判定一出，就交人（§6 时刻 1），附判定表、不超过 3 个选项，以及每个选项的算力代价。没有人的批准，不做一轮修。
6. **一轮修**：可调的量只有指令给出的这几个：β、η、`normalize`，以及 a/b 比例。a/b 比例只能在 N1、N2 之间换；要用别的 (a, b)，须先通过补充 D1 的 36 格（修改 1 N5），本节不包括这一步。修后的判定标「修后」，原判定保留。
7. **F1**：修后可学性仍不过，即为 F1，由人在 G1 决定 M12 结项，并按指令 §7 写机制性负结果。
8. **判据冻结**：看到任何 S1 结果之后，判据不再改。之后发现判据有缺陷，只能标 post-hoc，原判据的结论保留。
9. **一般纪律**：不读 E，不用 EEG；后台运行按 PID 跟踪；回执逐运行写出，可以恢复。

**B2 A2 检验力 —— 全部采纳。** A2 的判据改为以下 6 条全过（原「假阳性 = 0」保留为第 1 条）：
1. **假阳性 = 0**：certified 且（任一起点在 10⁶ 步内未达方程残差 ≤ 1e-9，或两起点平衡态之差超过下面第 6 条的阈值，或出现任何非有限值）。
2. **独立复算**：每个配置从稠密 W（`brain.dense()`，W[pre, post]）独立算 ρ̃_ref = maxᵢ∈free Σⱼ∈free |W_ji|·L_ref(a_j, b_j)，L_ref 取 v ∈ [−60, 60] 上 4×10⁶ 点稠密网格最大值与 `scipy.optimize.minimize_scalar` 有界优化（在 t± 附近的区间上）二者的较大值，不调用 cadence 的 L。要求 |ρ̃_cadence − ρ̃_ref| ≤ 1e-12·max(1, ρ̃_ref) + 1e-9·maxᵢ Σⱼ |W_ji|（后一项覆盖 L_ref 自身 ≤ 1e-10 的数值误差），且 certified 标志相同；ρ̃_ref ∈ [1 − 1e-9, 1 + 1e-9] 的配置不比较标志，单独计数。
3. **直接界检查**：对两个起点，每第 1 000 步的状态和终态上都要满足 ‖diag ρ′(v_f)·W_ff‖ 的行和 maxᵢ Σⱼ |W_ji|·|ρ′(v_j)| ≤ ρ̃ + 1e-12。
4. **检测器阳性对照**：≥ 200 个构造出多不动点的未认证配置：W_ff = w·(11ᵀ − I)/(n − 1)，w·L ∈ [1.5, 3]，c = 0，偏置 0，(a, b) 抽自同一分布。检测器（两起点不一致或不收敛）必须标出其中 ≥ 90%，否则 A2 记「无效」（不是「过」）。
5. **变异检验**：两个故意错误的证书——(α) 忽略 b、取 L = a/2；(β) 行权重取突触后的 L_i 而不是突触前的 L_j——跑同一生成器的全部配置，第 2 条的复算必须把每个变异都至少在 1 个配置上标出（实际报告标出的比例）。
6. **唯一性阈值（N3）**：两起点之差的假阳性阈值为 2·tol·(1 + m_in)/(1 − ρ̃) + 1e-9，tol = 1e-9 是 `equilibrate` 检查的方程残差 ‖F‖∞，m_in = maxᵢ Σⱼ∈src |W_ji|·L_j 是源到自由块的加权耦合。推导：源块误差 ≤ ‖F_src‖，自由块的映射以 ρ̃ 压缩，所以自由块误差 ≤ (‖F_f‖ + m_in·‖F_src‖)/(1 − ρ̃)。冷读给的 2·tol/(1 − ρ̃) 漏了源误差经输入突触的传递（输入突触幅度自由，m_in 可以 > 1）。
- 生成器补充：每个配置把自由神经元分成 1–4 个群体（各 1/4 概率），各群体独立抽 (a, b)；回执写群体数的分布。`equilibrate` 用 `damping=0`。源神经元一律线性（W5）。

**B3 A1 的未决情形 —— 采纳。** A1 成立 ⟺ 72/72 格在 CPU numpy f64 和 torch CPU f64 上都有效且满足。生产设置下任一种子拒相（`LearningPhaseError`）或出现非有限值 → 该格**不满足**（不是无效）。2 天墙钟到时仍有无效格 → A1 记「检验力不足」，G0 不过。任何格都不因梯度范数小或饱和比例高而被排除。

**数值核对**

- **Lipschitz 常数**：推导正确。ρ′ = ½(1 − t²)(a + 2bt) 与中心差分的最大绝对误差是 2.6e-11。两根之积为 −1/3，L 只依赖 |b|，这两点都成立。闭式解、v ∈ [−60, 60] 上 4×10⁶ 点的稠密网格、有界一维优化，三种方法在 (1,0)、(1,0.25)、(1,0.5)、(1,1)、(0,1)、(1,−1)、(0.2,±2)、(2,−2)、(1,2) 上一致到 1e-10。文中的例值 0.5、0.52815、16/27、0.75808、2/(3√3) 全部复现。另在 a ∈ U[0.2, 2]、b ∈ U[−2, 2] 上随机抽了 3 000 组，闭式值从未小于网格值。
- **非单调的条件**：ρ 非单调当且仅当 **|b| > a/2**。(1, ±0.51) 非单调，(1, ±0.49) 单调。
- **加权级联证书**：对非单调激活同样成立。证明只用到 sup|ρ′|，即 ‖(1 − dt)I + dt·W_ff·diag(ρ′)‖∞ ≤ 1 − dt(1 − ρ̃)，前提是 0 < dt ≤ 1；单调性不参与。行按突触后神经元 i 取，权重 L_j 取突触前神经元 j，与 cadence 的 `row_mass`（按 `post` 汇总）方向一致。在 298 个随机配置上（含贴边的 ρ̃ ∈ [0.95, 0.999)，1–3 个群体，(a, b) 异质），两个起点都收敛，两起点之差最大 3.2e-9，访问到的状态上 ‖W·diag ρ′(v)‖∞ 从未超过 ρ̃。
- **EP 的适用性**：ADR-0013 的 ∂Φ/∂v_i = ρ′_i·F_i 正确（W 对称时）。EP 恒等式只需要平衡点 s(β, θ) 可微，而这一点来自 F 上的隐函数定理，与 ρ′ 是否为 0 无关。但要注意：在 ρ′_i = 0 处，∇²Φ = diag(ρ′)(−I + W·diag ρ′) 是奇异的，Φ 的驻点也比 F 的零点多。所以论证只能用「F 的不动点 + 隐函数定理」来表述，不能说平衡点是「能量极小」。
- **A2 的检验力（关键）**：用 A2 的生成器做了两个故意错误的证书。(i) 忽略 b、取 L = a/2：300 个配置中有 157 个真实的加权 ρ̃ ≥ 1，按 A2 的定义检出的假阳性却是 **0**。(ii) 行权重用 L_i 代替 L_j：真实越界 9 个，检出 0。∞ 范数界非常保守，所以「收敛」几乎检测不到证书算错。照现在的写法，A2 = 0 对实现正确与否基本没有判别力。见 B2。

**指令一致性**：S0 覆盖了 §4 S0 的五个工作项和三条验收。S0.8 披露的偏离都合理：GPU 缺失、72 格的重构、H = 512 的保守换算、开发期与 2 天墙钟的区分、0.512 不含 EA。72 格的重构有正当理由：leak = 0.1 有折点，§2/§3 禁止，用单调与非单调两个光滑神经元替换 leak 轴，格数不变。判据比指令更严（deep 类也要 ≥ 0.999，cos(IFT, FD) 每个类别都要 ≥ 0.99999），这是允许的。下面的问题按阻塞与否分列，每条附建议的确切改法。

- **T1 输出神经元在证书下的结构上限（关键，见 B1）**：输出神经元的入边只来自隐层（N2），加权行质量 Σⱼ |W_oj|·0.75808 ≤ 0.9，所以 Σ|W_oj| ≤ 1.187；隐层发放在 (−0.25, 2) 内，因此对任何输入，v_out 的变化幅度 ≤ 1.187 × 2.25 = **2.671**（偏置是常数，不增加幅度）。在这个幅度内任取窗口，ŷ = 4·ρ_N1(v_out) 能达到的最大 R² = **0.928**；要 R²_out ≥ 0.9，v_out 至少要变化 **2.222**，即上界的 83%。这个上界假设每个隐层神经元都在自己的整个值域里与 x1x2 同步摆动，实际做不到（单个隐层神经元只是一个投影 w·x 加反馈的函数）。初始化时 ρ̃ = 0.6，对应幅度上界只有 1.781，R² 上限 0.856。把目标缩放 0.25 换成 c 时，R²_out ≥ 0.9 所需幅度：c = 0.15 时 1.235（上界的 46%），c = 0.1 时 0.806（30%），c = 0.05 时 0.398（15%）。
- **T2 生成器**（40 个数据种子 1000–1039，按 S1.4 原样生成：M 元素 N(0, 1)、列归一化、cond ≤ 10；训练、测试各 2 048 窗）：cond 重抽次数平均 2.5、最多 9；z-score 坐标下 u = (M⁻¹)_A·D 的定义正确，CSP 两端的广义特征向量与 u_A、u_B 一致，m_CSP 最小 0.99932；κ_oracle 最小 0.989，中位数 0.993（所以 0.9 × κ_oracle ≈ 0.89–0.90）。CSP 中间 4 个特征值在总体上都是 0.5（简并），「两端各 2 个」里的第 2 个来自简并子空间，m_CSP 只靠两端的那个。
- **T2 的匹配量**：随机 6 维单位向量 P(|cos| > 0.8) = **3.07%**（cos² ~ Beta(1/2, 5/2)），不是文中的「约 5%」。4 个随机滤波使 m ≥ 0.8 的概率按种子平均 1.7%、最高 5.3%；3 个种子中至少一个随机 arm 的 m ≥ 0.8 的概率约 **4.9%**。**|cos(u_A, u_B)| 中位数 0.41、最大 0.88**：u_A、u_B 在 z-score 坐标下不正交，有时很接近（见 B3）。
- **损失的尺度**：cadence 的 CE nudge 驱动是 β·(target − softmax(s/T))，`ep_eeg/ift.py` 对应的损失是 **T·CE(softmax(s/T), y)**（dL/ds_out = softmax − onehot），不是 S1.4 写的「CE/T」；两者差 1/T² = 100 倍（见 B4）。cadence 的 `contrast` 已除以 2β，`apply` 对互惠对取两方向均值、对绑定组取成员均值再乘 `synapse_rate`，所以 EP 的步长 = η·(−∂C/∂θ)（ep_equivalent 约定下）。S0 只用余弦比较 EP 与 IFT，余弦与整体尺度无关，**S0 没有核对过两者的大小一致**。

**指令一致性**：T1 的 H ∈ {8, 32}、二次 nudge、R² ≥ 0.9；T2 的 6 通道随机混合、窗 64、两类各降 50%、输入 6 × 64 展平、入口跨时间共享、0.9 × oracle、best-match |cos| ≥ 0.8（3 种子最小值）；T3 的 |κ_EP − κ_IFT| ≤ 0.03；G1 = T1 ∧ T2、一轮修（β、η、`normalize`、a/b）、仍不过 → F1；1 周墙钟——都在有效节里。T1 的随机湖条款按人选的 (c) 处理，合法（没有任何 S1 结果）。偏离与补全：T2 加了 4 个噪声源、u_A 与 u_B 两个都要匹配、κ 比值逐种子判、一轮修需人批准；这些的理由只写在作废节的 S1.10 第 5、6、9 条里，有效节没有披露（见 N9）。E 封存沿用 S0 的文件名核对 + 审计钩子，S1 不读 EEG，没有问题。

#### 阻塞（落实到「事后修改」之前不应运行任何 S1 正式运行）

**B1. T1 (ii) 在证书下由构造几乎不可满足。** 见上面的核对：投影上限 ρ̃ ≤ 0.9 把输出神经元的输入幅度限制在 2.671 以内，ŷ = 4·s_out 的 R² 硬上限是 0.928，达到 0.9 需要所有隐层神经元在全值域上协同摆动到上界的 83%。这与人选 (c) 之前随机湖 + ridge 的情形同类：T1 会因为常数 4 和证书上限的组合而不过，触发 F1，原因不在 EP。常数 4 是起草者在修改 5 写进去的实现细节，人的原话只要求「在输出神经元上判，EP 输出 R² ≥ 0.9，随机湖输出 ≤ 0.3」。
- **改法**：把 nudge 目标改为 t = clip(0.1·x1x2, −0.7, 1.2)，ŷ = 10·s_out（不拟合，常数写死），所需幅度降到上界的 30%；在 `/tmp` 上重算并写明新上限（c = 0.1 时 ŷ = 10·t 几乎不截断，上限 ≈ 1.0；在可达幅度 2.671 内最大 R² 0.998）。代价是二次 nudge 的误差信号按 c 缩小 2.5 倍，η 固定 0.05 时学习更慢；如果担心这一点，c = 0.15（ŷ = s_out/0.15，所需幅度 46%）是折中。
- 因为这改动了修改 5 里 ŷ 的写法，要在事后修改里写明是冷读意见，并告诉人；阈值 0.9、0.3 与「不拟合」都不变。

**B2. 「失败种子按最差值计」的方向写错，会让对照判据和有效性检查自动通过。** S1.7 规定失败种子取 R² = −∞、κ = −1、m = 0。对「≥」判据这是最差值，但对 (iii)「随机湖 R²_out 3 种子最大值 ≤ 0.3」，R² = −∞ 会让 (iii) 通过；对 T2 有效性「随机 arm 与打乱标签 arm 的 m 最大值 < 0.8」，m = 0 也会让它通过。
- **改法**：写成「失败种子按对该判据**最不利**的值计：≥ 型判据取 R² = −∞、κ = −1、m = 0；≤ 型判据与对照 arm 的有效性检查取 R² = +∞、m = 1」。T3 中任一 arm 有失败种子 → T3 记「不过」。

**B3. T2 的匹配量可以被一个滤波同时满足，而且有效性检查失败时没有出路。**
- (a) |cos(u_A, u_B)| 最大 0.88。夹角 28° 时，一个居中的滤波对两者的 |cos| 都约 0.97，m = min(max_k |cos(w_k, u_A)|, max_k |cos(w_k, u_B)|) ≥ 0.8 成立，但这个滤波并没有分出 A 或 B。**改法**：m 改为必须由**不同的**滤波匹配：m = max_{k ≠ k′} min(|cos(w_k, u_A)|, |cos(w_k′, u_B)|)，m_CSP 与随机、打乱标签 arm 同样计算；生成器在 cond(M) ≤ 10 之外再要求 |cos(u_A, u_B)| ≤ 0.5（u 按真 D 计算，即混合后各通道的理论 SD；重抽次数写进回执）。
- (b) 随机 arm 的 w_k 就是 EP 运行的初值，3 个种子里至少一个随机 m ≥ 0.8 的概率约 4.9%。照现在的写法，这时 T2「无效 → 修数据或代码、同样的种子重跑」，但没有可修的错误，结果确定，T2 永远无效、G1 不可判。而且 EP 从同一初值出发，(EP 的 m ≥ 0.8) 不能说明学到了东西。**改法**：随机 arm 的 m 只依赖初值，写死「在任何训练运行之前计算 3 个正式种子的初值 m 并提交；若某种子 m_init ≥ 0.8，该种子的初值种子改为 seed + 10、+20……直到 m_init < 0.8，替换规则与次数写进回执」。这只看初值，不看任何训练结果。打乱标签 arm 的 m 仍作有效性检查；它若 ≥ 0.8，判 T2 无效并交人（不是修代码）。

**B4. T3 的两条训练器尚不可比。**
- (a) S1.4 写 IFT 的损失是「CE/T」，而 cadence 的 EP 在 β → 0 时对应 T·CE（`ep_eeg/ift.py` 的约定），两者差 100 倍。**改法**：写成「C = T·CE(softmax(s_out/T), y)，batch 均值，∂C/∂s_out = softmax(s_out/T) − onehot」。
- (b) IFT 的步长路径没写死。**改法**：IFT 的每次更新写成 `L.apply(η·c, η_bias·c_b)`，(c, c_b) = `ep_equivalent(implicit_grad(...))`，与 EP 经过同一个 `apply`（同一 `synapse_rate` = `tie_rates`、同一互惠均值、同一绑定组均值），然后做同一投影。删去「Δθ = −η·g_IFT，绑定组用组内求和梯度」这句，以免实现者在 `apply` 外再乘一次组大小。
- (c) **准入（尺度）**：S0 只核对了余弦。T3 运行前，在 T2 图（开发种子 101 的初值、一个批）上要求 ‖Δθ_EP‖ / ‖Δθ_IFT‖ ∈ [0.98, 1.02] 且 cos ≥ 0.999（全部参数与入口绑定组各自），否则 T3 不运行、修实现。
- (d) IFT 在容限 1e-9 的紧平衡上算；写明紧平衡在 50 000 步内达不到 1e-9 时该批「拒更新」，计入 U 与拒更新数，与 EP 的拒更新规则（> 5% → 种子失败）相同。EP 拒掉而 IFT 接受的批（以及相反的）逐批记入回执，T3 表中报告两者实际施加的更新数。

**B5. 有效 S1 节没有准入检查，违反指令 §3 和 S0 的做法。** 作废节 S1.9 里的准入检查 (a)–(d) 没有并入有效节；S1 又用了 S0 没有检验过的新代码：加权行质量投影（按 L_j 加权、互惠对同乘、输入边与绑定组不动）、连续目标的二次 nudge（`Learner.targets` 只接受类别标签，T1 要自己构造 (batch, n) 目标）、T1 输出 N1 + 隐层 N2 的组合。**改法**：在有效节加「S1 准入检查（开发种子 ≥ 100、(a, b) = (1, 0.6)，不过则不运行对应任务；全部进入 G1 判定表）」：
1. 投影：一次投影后 `certified == True`、ρ̃ ≤ 0.9 + 1e-12、源 → 自由的边逐元素不变、绑定组内效能最大差 ≤ 1e-12、互惠对两方向差 ≤ 1e-12；投影前已满足上限的图逐元素不变。
2. T1 连续目标：二次 nudge 的 IFT 梯度对中心差分（h = 1e-4，1e-11 紧平衡）cos ≥ 0.99999；EP（生产 β 与容限）对 IFT cos ≥ 0.999，3 个开发种子最小值。
3. EP 单步：手动三相 + `contrast` + `apply` 与 `Learner.step` 的单次更新逐元素相对误差 ≤ 1e-12（T1、T2 图各一次）。
4. 生成器自检：T2 的 cond(M) ≤ 10、|cos(u_A, u_B)| ≤ 0.5（B3）、类别平衡、数据 SHA-256 从种子可复现；T1 的 x 的 SHA-256 可复现。
5. B4(c) 的尺度检查。

**B6. 修一轮的 η 网格不含 0.05，必须在看到结果前定下来。** 修改 6 认为 {0.02, 0.1, 0.5} 都与首轮不同是优点，但后果是修一轮里的每一个组合都同时改了 η：若首轮的问题在 β 或 `normalize`，修一轮无法在 η = 0.05 下只改它们，结果也分不清是哪个量起作用。修一轮的规则只能在看到 S1 结果之前改，之后再改就是 post-hoc。**改法**：η ∈ {0.02, 0.05, 0.1, 0.5}，组合数 3 × 4 × 2 × 2 = 48；S1.11 的最坏预算相应改为 144 × 65 分钟 / 4 ≈ 39 小时，加正式重跑约 5 小时，仍在 1 周内。若有意保留现网格，在事后修改里写明「修一轮不能在 η = 0.05 下单独改 β、`normalize` 或 (a, b)」，并由人确认。
