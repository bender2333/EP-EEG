# M6 阶段报告：拉长 EP 沙盘训练（epochs）

**台账区间**：stage=M6（fast 筛选 + full 确认）。  
**旋钮**：只改 `epochs`（默认 10 → 20 / 50 / 100 = 2x / 5x / 10x）。**不**改 `free_steps`/`nudged_steps`（二者是每批 EP 求解预算，不是数据遍数）。  
**基线 opts**（M1 最佳）：`leak=1.0, rowmass_project=0.9, eta=0.5, temperature=0.01`；arm=`ep_track2`。  
**对照**：同输入 LDA Track-2 κ_val = **0.3889**（M0 full）；M1 1x epochs=10 κ_val = **0.2870**。

## 为何缩放 epochs 而非 free_steps

- `epochs`：整集训练遍数，直观对应「训练更久」。
- `free_steps` / `nudged_steps`：单次 `Learner.step` 的求解步数预算；加长它们提高每批收敛成本，不等于多看数据。
- M1 搜索曾单种子试过 epochs=20（κ≈0.28）与 30（过拟合）；本阶段在冻结 opts 下系统确认。

## 协议（四要素）

1. **数据**：BCI Competition IV-2a，经 MOABB `BNCI2014_001` / `eval/t_only_bnci` 加载；9 名被试；T 会话 run 0–3 训练、run 4–5 验证；四类运动想象（左/右手、脚、舌）。E 会话本阶段未评（非阶段门主结论所需；κ 未过 LDA）。
2. **输入**：与 M0–M5 冻结管线一致——每 run 去均值 → EOG→EEG 线性回归（仅用 T run0–3 拟合）→ 4–35 Hz 零相位带通 → 按导联 Z-score → 11 个子窗（cue+0.5..3.5 s，500 ms / 250 ms hop）→ **Track-2 Hjorth**（activity / mobility / complexity，每导 3 维 → **66 维**）→ 训练集 FeatureScaler → `tanh(x/3)` 压缩后驱动沙盘。
3. **训练时长 / 硬件**：见下表 `wall_s`（含训+验；8 核 CPU、无 GPU；`NUMBA_NUM_THREADS=2 OMP_NUM_THREADS=2`，`--jobs 4`）。
4. **κ**：验证集 Cohen's κ（9 被试均值；full 另报种子间 sd）。

## 结论

- **未追上同输入 LDA（0.3889）**。最佳确认档为 epochs=100（10x）：κ=**0.3354**，距 LDA 仍约 **0.054**。
- 相对 1x（0.287）：2x 微升（+0.01）、5x 明显升（+0.04）、10x 再微升（+0.05）；**收益递减**，不像单纯欠训。
- 种子方差在 5x/10x 上很小（sd≈0.001–0.002），结果稳定。
- 与 M1「epochs=30 过拟合」的单种子观察一致：拉长训练不能弥合与线性读出的差距；瓶颈更可能在表示/动力学容量，而非 epoch 预算。

## 负结果

主假设（拉长 epochs → κ ≥ LDA）**不成立**。

## 待决 / 后续（不阻塞记账）

- 是否改 `free_steps` 或学习率日程：本阶段刻意不动，以免混淆自变量。
- 跨被试预训练、更大 k、连续目标：仍属人拍板项（见 AGENTS / ADR-0009）。

## 下一阶段建议

若继续诊断：优先查「固定沙盘 + 更强读出」或特征–动力学匹配，而不是再堆 epochs。
