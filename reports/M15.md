# M15：平衡传播的学分停在出水口的尺度上，不停在某一层的方向上

预注册在 `reports/M15_prereg.md`。全部用 T 场：训练 run 0–3，验证 run 4–5。没有下载、没有读取留出集。`eval/` 和 M14 已发表的选参数字没有改。合格率除特别写出的地方都是 1，拒判都是 0。

线程变量设为 2。本机 2 个 CPU，确认运行改成每个作业 1 个线程、两个作业并行。

## 5. 学分停在哪里

在 M14 实际用的 β=0.04 上，平衡传播的步和自由相交叉熵的下降方向在前端、沙盘和出水口上都对齐（余弦多在 0.9 以上），模比各层相同，大约是温度 0.01。学分没有在某一层把方向丢掉。β 加大到 0.1 会在部分被试上把侧向打反，那不是现在这条训练曲线的工作点。

停住的地方是出水口活动的尺度。臂 C 的四个出水口挤在 0 附近，标准差约 6e-4，裕度约 0，饱和比例 0。线性读出还能用这四个小数（LDA 0.500），argmax 不能（0.416）。把特征标准化之后，普通逻辑回归回到 0.492；平衡传播的线性头到 0.433，仍差一截。C_skip 不把尺度放大，只把裕度的符号改成正的，判决就到 0.509。

前端的 0.54 不是「频带功率的上限」。逐导联对数方差只有 0.485，FBCSP 是 0.612。差在空间滤波。

## 7. 没跑的，和 M16

- 块 3 的三个沙盘消融：预注册的启动条件没有满足。
- 把滤波器组再送进完整的 C_skip：预注册里明确不跑。
- 筛选里没提升的三个候选：没有九人续跑。

把出水口突触的步长乘 5，在 U=3000、种子 0 上只多 0.029（7/2/0，p=0.016）。学习率不是那 0.10 的缺口。

M16 值得做的是：把出水口从 1e-3 拉到可读的尺度（增益或偏置；C_skip 已经说明一条跳连就够把 argmax 拉回来），以及在前端加空间滤波。不值得先做的是：在 β=0.04 上拆侧向，或靠把 β 加大、或只把出水口步长加大来修判决。
