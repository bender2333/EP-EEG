## E0 入场券：留出电极重建（预注册）

### E0.1 问题

把 22 个电极藏起几个，v0 湖能否用其余电极推回被藏的信号，并且明显好于：同一个未训练的随机湖（同样的读出）、几何插值（球面样条）？以及：打乱电极位置后，依赖位置的方法是否变差（任务本身确实带空间信息）？

### E0.2 留出方案（清单 §8 留给我们的问题：怎么设计才公平）

22 个电极是稀疏浮标，反问题有无穷多解，所以「公平」的意思是：所有方法在同一组隐藏模式、同一批样本上，只用可见电极，而且任何方法都不能经由预处理偷看被藏的电极。决定如下：

1. **两族隐藏模式，全部固定、事前列出**（`m13_common.patterns()`）：
   - **P3（主判据）**：每个导联连同离它最近的 2 个导联（standard_1005 欧氏距离）一起藏，去重后 22 组（恰好无重复），每组藏 3 个。理由：22 导联间距约 3 cm，单藏一个时最近邻几乎照抄就能得高分，测不出「学到的空间结构」；把最近的两个邻居一起藏，重建必须来自第二圈以外的电极，空间结构才起作用。
   - **P1（次判据）**：每个导联单独藏，22 组。
   - 每个导联在 P1 里恰好被藏一次，在 P3 里至少一次；边缘导联（Fz、C5、C6、POz）与中央导联都在内，不挑好做的位置。
2. **防泄漏**：IV-2a 以左乳突为参考，冻结预处理里没有共平均参考、拉普拉斯或任何跨导联变换（`eval/preprocess.py` 文档串「No channel-mixing transform is applied to EEG」）；EOG 回归逐导联独立。所以被藏导联的信号不会混进可见导联。湖的被藏导联输入置 0 并给一个「被藏」标志；`test_m13.py::test_no_leak` 验证改动被藏导联的值后湖的所有状态逐位不变。
3. **样本**：每个试次取 cue+0.5–3.5 s 的 750 个样本（冻结评估层的段），按每 5 个取 1 个（50 Hz 网格）。训练行 192 × 150 = 28 800；读出拟合行按每 10 个取 1 个（14 400）；评估行 96 × 150 = 14 400（run 4–5）。v0 是静态平衡湖（ADR-0001），每个时间点独立重建；后面的振荡湖可以用可见电极在同一段内的时间上下文，被藏电极在任何时刻都不可见。
4. **一个湖服务所有模式**：湖按「随机遮罩」训练，每个训练行随机抽 P1 ∪ P3 中的一个模式（种子决定），所以每名被试 × 种子只训练一个湖；读出按模式分别拟合。
5. **量**：每个被藏导联在评估行上的 R² = 1 − Σ(ŷ − y)² / Σ(y − ȳ)²（y 为 z 分数信号，ȳ 为评估行均值），先对一个模式内的被藏导联平均，再对同族模式平均。被试分数 = 3 个种子的均值（插值没有种子）。

### E0.3 v0 湖（只记录，不改）

M12 结项时的湖，按 ADR-0002 的微柱布局：

- 源（线性，不经激活）：每个导联 2 个——值 tanh(x/3)（被藏时 0）与被藏标志（0/1）。共 44 个。
- 微柱：每个导联 k = 4 个 N2 = (1, 1) 偶分量神经元，共 88 个；每个导联的 2 个源只单向注入它自己的 4 个微柱（权重 N(0, 1)）。
- 微柱之间全对称互通（N(0, 1/88)）；22 个出水口（N1 = (1, 0.25)，每个导联一个）与全部微柱双向（N(0, 1/88)）。
- 学习：EP、二次 nudge，目标 = 0.5·tanh(x/3)（对所有 22 个导联，含可见的），β = 0.04、η = 0.05、容限 3e-3、qualified、damping 3、batch 64（M12 首轮值）；**U = 6 000 次更新尝试**，不早停，评估最终状态。初始化把 free→free 缩放到 ρ̃ = 0.6，每次更新后做对称的加权行质量投影到 ρ̃ ≤ 0.9（M12 的 `project`），全程 certified。
- 评估态：紧自由平衡（容限 1e-5），记合格率与不合格行数。
- 后端 cadence fork `m12`（`7559f0c`）cpu f64，单线程作业。

v0 不读取任何电极坐标：这一点是 ADR-0002 g1 的性质，也决定了「打乱电极位置」对 v0 的含义（E0.4）。

|---|---|---|
| `lake` | EP 训练的 v0 湖；按模式取全部微柱的平衡态，标准化后 RidgeCV（α ∈ logspace(−3, 4, 15)，训练集内选 α）读出被藏导联 | 是 |

**打乱电极位置对 v0 的处理（决定与理由）**：v0 不读位置，把导联打乱后再训练，得到的是同一个网络换了标号，分布上与 `lake` 完全相同，单独跑一遍只会得到种子噪声。所以对 v0 用一个精确检验代替这次运行：`test_m13.py::test_v0_is_position_free` 证明按错排重新布线的湖在同样错排的数据上，平衡态与一次 EP 更新都与原湖逐元素一致（≤ 1e-8）。这说明 v0 的任何得分都**不能**归功于电极几何。依赖位置的方法（样条，以及 C 步的场）才有「打乱位置」这一对照可比；E0 用 `spline` 与 `spline_shuf` 检验任务本身带不带空间信息。

## 2. A–F 的判据框架（每步细节在运行前另行提交）

共同口径：任务 = E0 的 P3 重建 R²（同样的行、模式、读出、9 名被试 × 3 种子），每一步与「上一版保留的湖」比。**保留** ⟺ 新版 > 上一版的被试 ≥ 7/9 且单侧 Wilcoxon p < 0.05；否则丢弃，从上一版继续（B 除外，见表）。每步另有清单写明的专门检验：

- **A 相位输入**（§4.1）：冻结湖底只训读出，相位 + 功率输入对纯功率输入。被藏导联的目标不变（原始 z 分数信号）；相位只来自可见导联。
- **B 二阶振荡微柱**（§4.2）：静态平衡换成动力学，违背 ADR-0001 的「子窗静态平衡」，所以 B 运行前先写 ADR-0014（proposed）交人。学习不动：B 的湖固定，只训读出；与一阶 v0 在同一重建任务上比。另报：湖的自发功率谱峰是否在 8–13 Hz。B 不过 → 振荡结构没有带来任何重建收益，C、E 的前提不成立，M13 结项。
- **C 场变量**（§4.3）：场必须有空间梯度能（否则等价于全连接平均场，清单写明的陷阱）。消融：关掉场，重建变差才算场有用；此步「打乱电极位置」成为真对照（场读位置）：真实位置 > 打乱位置 ≥ 7/9。
- **D**（§4.4，可选）：只在 A–C 至少一步被保留后做。
- **E 学习规则**（§4.5）：旋转部分固定，只学能量下降部分的耦合，局部更新；对照 = 同一湖不学。离开纯梯度系统后 EP ≡ 反向传播的保证不再成立，结论里写明。
- **F 三层评测**（§5）：结构验证（左/右手想象时场或同步度热点是否落在 C3/C4 附近，打乱电极、打乱时间下应消失）、前半段预测后半段、冻结湖 + 线性读出的下游探针（只要求明显优于打乱标签对照，不要求打赢 CSP）。

## 4. 清单 §4.5：湖带着场重新学习（运行前提交，2026-11-07）

**为什么这样做**：C 的结果说明两件事。第一，场挂在正负号随机的微柱上时，平滑的是与导联值无关的量，读不到位置；第二，湖没有在场存在的情况下学过，场只能当一个幅度旋钮。§4.5 改学习：让湖带着场重新学。先做最便宜、EP 仍然精确的一条路（第一条路），只有它显示湖用上了位置，才做在时间里学习的第二条路。

**第一条路（本节）**：准静态场放进能量，静态平衡，EP 学习规则不变（与 E0 相同的 `ep_step`、批、模式、目标）。代码 `ep_eeg/m13_learn.py`。
- 场挂在 **22 个出水口**上（出水口被训练成 0.5·tanh(x/3)，带符号、与导联值成比例），不再挂微柱。
- 场 = 出水口之间固定（不学）的对称突触 Q = λ·Goff / max 行和，G = (I − ℓ²L)⁻¹ 取电极节点块，**去掉对角**（不给自耦合，场加的东西只能来自别的电极；C 里自耦合与增益校准混在一起）。网格与 C 相同（`m13_dyn.mesh`）。
- 增益投影把场的行质量算进 ρ̃ ≤ 0.9，只缩可学的突触，场不缩。v0 已在上限，所以加场时先把出水口行（及对称的微柱–出水口突触）缩到给场让出空间；真位置与错排从同一个缩过的湖出发。证书 ρ̃ < 1 每步检查。
- 起点：E0 正式检查点（U = 6 000），每名被试自己的湖；再训练的批流与 E0 的不同（种子 + 1000）。
- 条件（同一被试、同一起点、同样的批）：`field` 真实电极位置；`der` 同一个 Q 按固定错排 `derangement(k)` 放置（强度和度分布相同，几何错）；`none` 不加场，同样再训练（把「多训练」与「场」分开）。

### A：输入保相位

`static`（v0 原样，逐行静态平衡，热启动不动点迭代）在 18 份作业上复现 E0 的 `lake_own` 到 1e-7 以内。把输入换成 Hilbert 幅度后湖的出水口失去符号，`lake_own` 掉到 −1.0 左右，9/9 被试都更差（p = 0.002）。这一步确认的是重建任务需要相位、v0 的输入已经带着相位，所以「保留」= 不改输入。回执 `receipts/M13/A/test/`。

### B：二阶振荡微柱（ADR-0014）

开发划分上四个阻尼都远低于基线：ζ = 0.05 / 0.2 / 0.5 / 1.0 的 `lake_own` 均值 −2.12 / −0.65 / −0.26 / −0.12，按规则选 ζ = 1.0（最接近一阶）。测试划分上 −0.119，0/9 被试胜过 v0，也 0/9 胜过同样在时间里跑的一阶湖（`dyn1` 0.553）。

两层原因，分开写：
1. **湖一旦在时间里跑就有滞后**：`dyn1`（神经元时间常数 2 ms）就从 0.761 掉到 0.553。v0 的增益上限 ρ̃ = 0.9，最慢的模态时间常数约 2 ms / (1 − 0.9) = 20 ms，对 8–30 Hz 的信号已经是明显的相位滞后。v0 的权重是在「瞬时到达平衡」下训练的，没有为滞后做任何补偿。
2. **振荡器再加一层**：10 Hz 的阻尼振子是 10 Hz 附近的带通/低通，ζ 小时在 6–8.5 Hz 处共振（白噪声驱动的出水口功率谱，`receipts/M13/B/spectrum.json`；有递归时共振频率低于 f0），ζ = 1 时是强低通（1–5 Hz 功率是 20–30 Hz 的约 60 倍），重建要的 8–30 Hz 波形被严重扭曲。

空间诊断随之崩掉（`cos_spline` −0.04，`rho_dist` 0.17）。结论：在不重新学习的前提下，给 v0 加惯性只会让它跟不上输入；B 的问题不是「振荡没用」被证明了，而是**固定 v0 权重 + 振荡**这个组合没有任何收益。清单 §4.5（在振荡湖上学习）是唯一能回答「振荡有没有用」的一步。

### C：场变量（ADR-0014）

开发划分第一轮 18 个准静态设定里 17 个收敛（挂微柱、ℓ = 2 cm、α = 1.0 不收敛，排除），均值 0.763–0.795；选定挂微柱、ℓ = 2 cm、α = 0.6（0.795；挂出水口、α = 1.0 的 0.794 在 0.005 以内，按规则取较小 α）。第二轮有传播的场（c = 0.5、2 m/s）均值 0.536、0.531，主要是上面说的「在时间里跑」的滞后，保留准静态。

测试划分：场 0.797 对 v0 0.761，9/9 被试变好（p = 0.002，+0.035），按规则**保留**。但：
- **真实电极位置 vs 错排**：6/9，p = 0.21，均值差 0.0001。场读不到位置。
- **空间诊断**：`cos_spline` 0/9 变好（0.445 → 0.437），`rho_dist` 0.673 → 0.666。
- **随机湖 + 同一个场**：−0.002，场本身不做插值。
- **增益从哪来**：ℓ = 2 cm 时相邻电极节点之间的耦合只有自耦合的 8%（电极最近间距 2.8–4.1 cm），场实际上把每个导联自己的 4 个微柱耦在一起，相当于抬高了出水口的增益。v0 的出水口本来就偏小：A01 种子 0 的 6 个 P3 模式上，真实值对 v0 重建的回归斜率 1.48，乘上最优标量后 R² 0.725 → 0.810；场把斜率拉到 1.26，R² 0.762（再乘最优标量 0.797）。也就是说场的 +0.035 是幅度校准，一个标量也能做到，而且做得更好。
- **事后探索（不在预注册里，不进判定）**：挂微柱、ℓ = 8 cm、α = 1.0（相邻节点耦合升到自耦合的 38%），种子 0：0.795，错排 0.795（6/9，p = 0.37），`cos_spline` 0/9 变好。长程场同样不读位置。回执 `receipts/M13/Cx/`。

### 空间关系（人点名的重点）

把湖的重建对 19 个可见导联做最小二乘，看湖「隐含」用了哪些电极：

| | 与样条权重的余弦 `cos_spline` | 权重与距离的 Spearman `rho_dist` |
|---|---|---|
| 数据自身（真实值对可见导联） | 0.769 | 0.568 |
| v0 一阶湖 | 0.445 | 0.673 |
| B 振荡（ζ = 1） | −0.036 | 0.168 |
| C 场 | 0.437 | 0.666 |
| C 场，错排电极 | 0.437 | — |

读法：v0 湖确实学到了「离得近的电极更重要」（`rho_dist` 0.67，比数据自身的线性最优映射还偏向近处），这一点来自 E0 的训练（A–C 都没有再学习）。但权重的形状和样条差得远（余弦 0.45 对数据的 0.77），这就是它输样条的地方。B、C 都没有把这个形状往样条推：B 破坏了它，C 没动它。A–C 都不训练，所以这个结果本来就不该期待「湖学到更多空间关系」，场能给的只有几何本身，而它在这里没有被用上（挂上去的是正负号随机的微柱活动，场的平滑不等于对导联值的插值）。

### 对下一步的判断（不在本阶段做）

- 唯一保留下来的改动（C 的场）是一个可以用标量替代的幅度校准，不是结构收益。要让场读位置，场得耦合在「带符号、和导联值成比例」的量上，而且湖要在场存在的情况下重新学（清单 §4.5）。
- 振荡和传播都要求湖在时间里跑，而 v0 是在瞬时平衡下训练的，一跑就滞后。§4.5 若要做，训练也必须在时间里做（让学习看见滞后），否则 B、C 的动态版本会重复这里的结果。
- 「追上样条」：9 名被试里没有一名被试在任何一步追上样条（最好的 C 仍差 0.158）。
