# M16 预注册：出水口尺度，以及空间滤波前端

写在任何 M16 运行之前。不改 `reports/M14.md`、`reports/M15.md` 的已发表数字，不改 `eval/`，不读留出集。训练 run 0–3，验证 run 4–5。配对检验是 Wilcoxon 符号秩，双侧。事后加的分析标探索性。

界：验证准确率差 0.05 才叫「明显」；差的绝对值 < 0.02 叫「对齐」。本机 1 个 CPU，下面的人数和种子是上限，不是必须把没过线的候选加长。

## 块 1 出水口尺度（没有跳连）

M15 的结论：β=0.04 时各层更新方向是对齐的，臂 C 的出水口活动约 1e-3，argmax 比同一状态上的收缩 LDA 低约 0.08。全局正增益不改变 argmax。要改的是训练把平衡点拉开的方式。

底子是臂 C（η=0.3）。最多 3 个候选，被试 1、3、8，种子 0，U=1500。

| 候选 | 唯一改动 |
| --- | --- |
| temp_match | 交叉熵温度 1e-3（贴近出水口标准差；原来是 0.01） |
| temp_mid | 温度 3e-3 |
| out_budget | 出水口通路初始化预算 0.7、侧向 0.05（原来 0.5 和 0.15），初始化证书必须通过，否则这个候选记 crash、不替换 |

每个候选训练后，在它自己的出水口状态上再拟合收缩 LDA。提升规则，最多提升 1 个：

- 三人上（LDA − 判决）的均值 < 0.02，并且判决均值 ≥ 0.45；或
- 没有候选合上这个缝，则取得分最高者，但只有它比这三人、U=1500 的 C（网格里已有，均值 0.385）高 ≥ 0.03 才提升。

提升之后：九人、U=3000、种子 0。种子 1、2 只在种子 0 的判决比 C 的种子 0 高 ≥ 0.03，或九人上（LDA − 判决）< 0.02 时才跑。

通过的那个旋钮再在 C_skip 上、同样的三人、U=1500 试一次（这是第 4 个、附在赢家上的组合，不是独立网格）。它的判决均值比这三人的 C_nolake（U=1500 若网格里有，否则用 U=2000 的已有数并写明）高 ≥ 0.03，才进入块 3。

## 块 2 空间滤波前端

M15：逐导联对数方差 LDA 0.485，FBCSP 0.612。差在空间滤波。

**2a，便宜，九人，种子 0，不训大网。** 用和 `baselines.fbcsp` 相同的 8 个频带、每带 4 个 CSP，只在 T 场 run 0–3 上拟合。

- 32 维 CSP 对数方差上的收缩 LDA。
- 同样 32 维、按训练集标准化后的平衡传播线性头。
- FBCSP+LDA 用 M15 种子 0 的已有数（同一代码、同一划分），不重算，除非实现被改过。

判定：标准化 EP 头与这 32 维 LDA 的差 < 0.02，则平衡传播读得了 CSP 特征。低 ≥ 0.05 且 p<0.05，则读不动。32 维 LDA 比 FBCSP 低 ≥ 0.05，则选择 8 个特征本身有贡献，写出来，不因此再加候选。

**2b，最多 3 个候选，被试 1、3、8，种子 0，U=1500。** 底子仍是臂 C 的时间窗网络，只换前端矩阵 W 的初值（W 的布局与 `front_matrix` 一致：行是滤波器、列是导联）。

| 候选 | W |
| --- | --- |
| csp_train | 8–30 Hz 上 22 个 CSP 滤波器，Frobenius 范数配到原来的平均参考初值，然后可学 |
| csp_frozen | 同上，但前端突触不可学 |
| rand_front | 同范数的随机矩阵，可学 |

报告验证准确率、W 相对初值的变化、以及和 CSP 初值的余弦。`csp_train` 比 `csp_frozen` 高 ≥ 0.03，才说平衡传播改善了这个空间滤波，并只把 `csp_train` 提升到九人、种子 0、U=3000。没有这 0.03，2b 不进块 3。对齐余弦只在被提升的那一个上、用 M15 的同一套有限差分补测一次（探索性测量，不新增候选）。

## 块 3 组合

只在块 1 有一个被提升的尺度旋钮、并且（若 2b 也提升了）用那个前端时才跑。最多两个网络：

- 尺度旋钮 + 跳连，前端用 2b 的赢家，若 2b 没有赢家则用原来的平均参考。
- 同一前端的 C_nolake（没有沙盘）。

九人、种子 0、U=3000。和 FBCSP 种子 0 比。种子 1、2 只给其中判决更高的那一个，而且只在它比 C_nolake 高 ≥ 0.02 或离 FBCSP 的差 < 0.05 时才跑。

## 不跑的

留出集。块 1 没过线的候选不进九人。M15 已经测过的「出水口步长 ×5」不重复。完整的多带 CSP 放进沙盘里再训，除非 2b 的单带前端真的被提升。
