# M14：湖改用运动想象解码当目标，端到端从原始时间窗学

起点：M13 §10 诊断（重建目标没对齐：湖收敛成取平均、出水口功率只剩约 31%、重建训练反而降低 MI 信息）。
人在 2026-11-10 批准的方案（原话"按这个跑"）：每人单被试，T 场训练、E 场测试；提示后的原始 22 导联时间窗；
前端一层可学空间滤波，初始化成平均参考（软提示），和湖一起用 EP 训练；目标只用 4 类运动想象，不带重建；
不做固定预处理（不先算频带功率，不固定参考）。

## 1. 预注册（2026-11-10，跑 9 人网格之前写下）

### 1.1 网络（ep_eeg/m14.py）

一个子窗一行，整张网用同一条局部 EP 规则（cadence Learner，居中 ±β 对比）训练。

| 层 | 内容 |
| --- | --- |
| 源 | 22 × 32 个线性源：一个子窗的冻结评估层 EEG，250 → 62.5 Hz 重采样（抗混叠），32 个采样点 = 512 ms。提示后 0.5–3.5 s 内取 11 个子窗（步长 0.25 s）。 |
| 前端 | 每个时间点 22 个空间滤波神经元（奇函数 tanh(v/2)）。源 → 滤波的单向突触跨时间共享（cadence `time_shared_entry`）：一个可学的 22×22 矩阵 W，每个时间点同一个。初始化 W = 2(I − 11ᵀ/22)（平均参考，"car"）或 W = 2I（单位矩阵）。 |
| 湖 | 22 × 4 个微柱（ADR-0002）：虚拟通道 k 的 4 个柱与该通道 32 个滤波神经元双向相连（每柱一个可学的时间感受野）；柱之间全连接双向；柱与 4 个出水口双向。柱带偶分量（s = tanh(v/2) + tanh(v/2)²），自己能做平方。 |
| 出水口 | 4 个，只有奇分量（单调读出），所以所有二次能力只在湖里（或 C 的显式平方里）。交叉熵 nudge，温度 0.01。 |

试次判决：11 个子窗出水口活动取平均后 argmax（冻结聚合，eval/scoring.py）。

### 1.2 臂

| 臂 | 内容 | 作用 |
| --- | --- | --- |
| A | car 前端 → 湖 → 出水口 | 主线 |
| B | 单位矩阵前端 → 湖 → 出水口 | 平均参考提示帮了多少、会不会被训练改掉 |
| C | car 前端，滤波神经元换成近纯平方（s = 0.1 tanh(v/2) + tanh(v/2)²），每个虚拟通道一个池神经元以固定权重 1/32 收时间平均（不可学），柱读池 → 湖 → 出水口 | 进湖前给平方+时间平均：湖能否自己从原始波形学出功率 |
| nolake | car 前端直接接出水口（出水口与全部滤波神经元双向） | 湖要明显赢过它才算有贡献 |

### 1.3 协议

- 每人独立（单被试），不做跨被试。训练集 = T 场 run 0–3（192 试次），选参只看 T 场 run 4–5（96 试次）。E 场只在冻结之后对每个臂评一次（AGENTS.md 留出规则）。
- 选参网格（每个臂同一份预算）：学习率 η ∈ {0.3, 1.0}，U = 3000 次更新（批 64 行），每 250 次存一次权重并在 T 验证集上评一次。种子 0、9 人。
- 选参规则：每个臂取 9 人 T 验证准确率均值最高的 (η, U)。然后种子 1、2 用选定的 η 再跑；每个种子取 U_sel 那一刻的权重。
- E 评估：用这 3 个种子在 U_sel 的权重直接评 E（训练数据和 T 验证那次完全相同，权重是同一组）。
- 冻结层的输入：EOG 回归、4–35 Hz 每导联带通、z 分数（M0 起的冻结评估层，每导联独立，不混导联，不算功率）。这是唯一保留的固定处理，其余全部端到端。

### 1.4 判据（看 E 场准确率，每人取 3 个种子的平均）

- **主判据 A 明显赢过 nolake**：同时满足 ① 9 人里 ≥ 7 人 A > nolake；② 配对 Wilcoxon 单侧 p < 0.05；③ 平均差 ≥ 0.05。
- **C 对 A（湖能否自己学功率）**：C − A 平均差 ≥ 0.05 且 ≥ 7/9 → "平方要作为结构给它"；|C − A| < 0.05 → "差不多，端到端路线站住"；A − C ≥ 0.05 且 ≥ 7/9 → A 更好。
- **B 对 A（平均参考提示）**：同样以 0.05 和 7/9 为界说 A 好、差不多、B 好；另报学完后 W 离初值多远、与平均参考/单位矩阵的余弦。
- 参照（随机湖、C_nolake、FBCSP+LDA）只描述，不当门槛。
- 每个准确率同时报合格率（子窗收敛比例）和拒判试次数。
