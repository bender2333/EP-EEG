## 块 0 机制（测量，不是候选）

臂 C，种子 0，训练后权重。被试 1、3、8。另加 A01 的初始化，以及 A01 的 C_nolake 训练后权重，用来看湖的那几跳。一批 32 个训练子窗，随机种子 `17017 + 被试`，与 M17 同一批。β=0.04，居中对比。

每一层记自由相 |s| 的中位数、|s₊ − s₋| 的中位数、自由相 |ds/dv| 的中位数。每一跳记行和增益：接收神经元的 |ds/dv| 乘上来自该层的 |W| 之和，再取中位数。向后的三跳是出水口→微柱、微柱→池、池→前端。没有微柱时，向后的两跳是出水口→池、池→前端。

归因，先写死。令 R 为 M17 在同一臂、同一被试、训练后权重上的「出水口相对步长 / 前端相对步长」。本批再算一次相对步长，应和 M17 同一量级。

- 若 |Δs_前端| / |Δs_出水口| ≤ 1/20，结论是微扰沿深度衰减。
- 若前端突触的突触前 |s| 中位数 ≤ 出水口突触前 |s| 的 1/5，结论是前端的突触前活动偏小。
- 两者可以同时成立。谁的倍数更大，谁是主要项。
- 若向后各跳行和增益的乘积与 |Δs_前端| / |Δs_出水口| 相差不超过 3 倍，衰减和平衡点的局部增益一致。差得更多，就写成「符号对消或工作点斜率低于行和上界」，不把行和上界当成衰减本身。

同时记下每层自由相加权行质量，以及相对 0.8 的余量。余量决定块 3 的互惠头能不能加上去。

## 块 2 逐层归一化的步

目标相对步长固定为 3e-3，取自 M17 臂 C 出水口相对步长的量级，不在验证集上改。倍数截断到 [1, 100]，只放大，不压低已经更大的通路。

| 候选 | 规则 |
| --- | --- |
| lars | 每一跳、每一步，用一个标量把该跳的 \|ηΔ\|/\|w\| 中位数拉到 3e-3。批大小 64。方向在层内不变。 |
| rms_mom | 每一跳用该跳步长的均方根归一，再乘到同样的相对步长，然后动量 0.9。批大小 128。 |

方向检查，写在真实筛选之前，只在 A01、臂 C、训练后权重、一批训练子窗上做。有限差分沿用 M15 的抽样（每条通路最多 16 个参数）。逐层标量不改变层内方向：归一化后的前端步与原步的余弦应 ≥ 0.99。若归一化后的前端步与 −∇L 的余弦 < 0.5，而原步的余弦 ≥ 0.8，这个候选在真实数据上不跑。

## 候选 centered_offset

动机记在这里，不是结论。LeCun 的 Efficient BackProp 和 Schraudolph（1998）指出，输入没有中心化时，更新容易同号，学习变慢。居中的深玻尔兹曼机把能量写成中心化隐状态的函数（Montavon 与 Müller，2012；Melchior 等，2016，arXiv:1311.1354）。全正的突触前活动会让一次更新里的各项同号。M17 里前端批相干大约 0.15。这个候选问的是：把隐层活动减去一个偏移之后，相对步长、批相干、与真实梯度的余弦、以及准确率，相对臂 C 怎么变。

它与 lars、rms_mom、local_pool、local_column 合在一起，是本阶段全部五个训练候选。五个共用同一个九人提升名额。

网络、初始权重、η=0.3、β=0.04、温度 0.01、批大小 64、初始化种子，都与臂 C 相同。偏移 μ 是每个神经元一个数，加在池、微柱、出水口上。源神经元和前端滤波器不加偏移。

- 初始值：所有 μ = 0。第一步的对比因此与未中心化的对比相同。
- 更新：只在该步的自由相已经被接受、而且这一步的对比已经用旧的 μ 算完之后，μ ← 0.99 μ + 0.01 mean(s_free)。s_free 是该训练批自由相平衡点的活动，不是瞬态，不是微扰相，也不是当前批在更新 μ 时再算的一个新均值。学习率 0.01 和初始值 0 都不看验证集。
- 拒学的步不更新 μ。验证集的活动不进入 μ。
- 同一步的自由相、+β 相、−β 相使用同一个 μ，求解过程中 μ 不变。能量里的突触项用 (s − μ)。对比里的赫布项也用 (s − μ)，公式仍是居中的 ±β 对比。μ 在两相里相同，对比才是这条能量对权重的导数。
- 判决和交叉熵微扰仍作用在原来的活动 s 上，不作用在 (s − μ) 上。类别目标仍是独热。这样准确率可以和臂 C 直接比。
- 收敛证书和行质量上限只看 |W| 与激活函数的利普希茨常数，与臂 C 用同一套检查，在初始化和运行结束时各做一次。求解期间 μ 是常数，不改变 ds/dv，所以不进入行质量。偏置也不进入行质量。投影若触发，仍只投影 |W|。

筛选时除了和其他候选一样的准确率、κ、合格率、拒判数、W 的相对变化，还在训练结束后用同一批训练子窗（种子 `17017 + 被试`，32 窗，β=0.04）记下：每一层相对步长的中位数、批相干（定义与 M17 相同）、以及该步与 −∇L 的余弦。有限差分沿用 M15：每条通路最多 16 个参数，中心差分，步长 1e-3，自由相交叉熵，温度 0.01。这三项用来和臂 C 对照，不单独改提升线。

## 真实数据

五个训练候选都直接进入真实筛选，中间没有别的关卡。被试 1、3、8，种子 0，U=500，臂 C 的其余设置不变。对照是网格里 C 在 U=500 的这三人均值 0.455。

方向检查若淘汰 lars 或 rms_mom，该候选不进入这三人的训练。其余候选不受那条余弦门槛约束。

提升到九人、种子 0、U=1500，要同时满足：三人准确率均值 ≥ 0.485，W 的相对变化均值 ≥ 0.02，并且（池上收缩 LDA ≥ 0.54，或与 T 场 run 0–3 的 8–30 Hz CSP 前 4 个滤波器的子空间能量比初始化高 ≥ 0.05）。超过一条时，只提升三人准确率均值最高的那条。两人相差小于 0.02 时，按 lars、rms_mom、local_pool、local_column、centered_offset 的顺序取前面的一条。九人上的成功线是准确率均值比选定 C 的 0.416 高 ≥ 0.03，并且池探针或 CSP 子空间至少一条达到上面的水平。

每个准确率都带合格率和拒判数。前 20 步若单步中位时间超过 2 秒，或拒学超过一半，该候选记为 crash 并停掉，不改 β 或 μ 的学习率再试。
