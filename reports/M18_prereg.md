# M18 预注册：深层的平衡传播步为什么小

写在任何 M18 运行之前。不改以前各阶段的预注册数字，不改 `eval/`，不读留出集。训练 run 0–3，验证 run 4–5。配对是 Wilcoxon 符号秩，双侧。本机 1 个 CPU。事后加的分析标探索性。

界：验证准确率差 ≥ 0.05 叫明显；绝对值 < 0.02 叫对齐。筛选只在被试 1、3、8、种子 0。最多提升 1 个候选到九人种子 0。种子 1、2 只在九人种子 0 比选定的臂 C（准确率 0.416）高 ≥ 0.05 时才跑。

M17 已经把前端学习率乘一个常数 100。那个候选让 W 动了，准确率低于选定的 C。本阶段不重复那个常数。

## 块 0 机制（测量，不是候选）

臂 C，种子 0，训练后权重。被试 1、3、8。另加 A01 的初始化，以及 A01 的 C_nolake 训练后权重，用来看湖的那几跳。一批 32 个训练子窗，随机种子 `17017 + 被试`，与 M17 同一批。β=0.04，居中对比。

每一层记自由相 |s| 的中位数、|s₊ − s₋| 的中位数、自由相 |ds/dv| 的中位数。每一跳记行和增益：接收神经元的 |ds/dv| 乘上来自该层的 |W| 之和，再取中位数。向后的三跳是出水口→微柱、微柱→池、池→前端。

归因，先写死。令 R 为 M17 在同一臂、同一被试、训练后权重上的「出水口相对步长 / 前端相对步长」。本批再算一次相对步长，应和 M17 同一量级。

- 若 |Δs_前端| / |Δs_出水口| ≤ 1/20，结论是微扰沿深度衰减。
- 若前端突触的突触前 |s| 中位数 ≤ 出水口突触前 |s| 的 1/5，结论是前端的突触前活动偏小。
- 两者可以同时成立。谁的倍数更大，谁是主要项。
- 若向后三跳行和增益的乘积与 |Δs_前端| / |Δs_出水口| 相差不超过 3 倍，衰减和平衡点的局部增益一致。差得更多，就写成「符号对消或工作点斜率低于行和上界」，不把行和上界当成衰减本身。

同时记下每层自由相加权行质量，以及相对 0.8 的余量。余量决定块 3 的互惠头能不能加上去。

## 块 1 合成数据

22 导、32 个时间点、四类。混合矩阵 A 由种子 18018 的高斯矩阵做 QR，固定，训练和验证用同一个 A。判别子空间 U 是 A 的前 4 列。类别 k 的第 k 个潜源标准差 2，另外 3 个潜源标准差 0.5，其余 18 个潜源标准差 1。每个试次 32 个独立时间点，观测 x = A s。训练 192 个试次，验证 96 个，四类数量相等。种子 0、1、2 只改变样本和网络初始化（初始化种子 19000+种子），不改变 A。

网络是臂 C，η=0.3，β=0.04，温度 0.01，批大小 64，一个试次一个子窗。每个候选先跑种子 0、U=250。种子 1、2 只给种子 0 的子空间能量 ≥ 0.30，或比基线高 ≥ 0.05 的候选。

子空间能量 E = ‖W U‖² / ‖W‖²，U 先正交化。随机矩阵的期望大约是 4/22 ≈ 0.18。同时记平均主角（度）、验证准确率、κ、合格率、拒判数。

合成上的通过线，两条都要：三种子均值 E ≥ 0.35，且验证准确率均值 ≥ 0.50。没有通过的候选不进九人真实数据。

## 块 2 逐层归一化的步

目标相对步长固定为 3e-3，取自 M17 臂 C 出水口相对步长的量级，不在验证集上改。倍数截断到 [1, 100]，只放大，不压低已经更大的通路。

| 候选 | 规则 |
| --- | --- |
| lars | 每一跳、每一步，用一个标量把该跳的 \|ηΔ\|/\|w\| 中位数拉到 3e-3。批大小 64。方向在层内不变。 |
| rms_mom | 每一跳用该跳步长的均方根归一，再乘到同样的相对步长，然后动量 0.9。批大小 128。 |

方向检查，写在真实筛选之前，只在 A01、臂 C、训练后权重、一批训练子窗上做。有限差分沿用 M15 的抽样（每条通路最多 16 个参数）。逐层标量不改变层内方向：归一化后的前端步与原步的余弦应 ≥ 0.99。若归一化后的前端步与 −∇L 的余弦 < 0.5，而原步的余弦 ≥ 0.8，这个候选在真实数据上不跑。

## 块 3 局部目标

不改自由相的权重，所以收敛证书与臂 C 相同。微扰相在层上加一个开环类别电流：±β R[:, y]，β=0.04。R 的列在种子 18181 下取标准正态，再除以该列的均方根，使电流的均方根等于 β。正相和反相符号相反。

| 候选 | 电流加在 |
| --- | --- |
| local_pool | 22 个池神经元 |
| local_column | 88 个微柱 |

判决仍只读原来的 4 个出水口。块 0 若显示微柱的加权行质量余量 ≥ 0.05，再加一个探索性的互惠头 `head_column`（微柱与 4 个附加出水口互惠，附加边单独缩放到不把任何神经元推过 0.8）。余量不够就不建这个头，收据里写明余量。池上不加互惠头：臂 C 的池已经顶在 0.8。

## 块 4

只有合成通过线达到之后还有余量才做。不预先承诺具体臂。

## 真实数据

只把合成上通过的候选拿到被试 1、3、8，种子 0，U=500，臂 C 的其余设置不变。对照是网格里 C 在 U=500 的这三人均值 0.455。

提升到九人、种子 0、U=1500，要同时满足：三人准确率均值 ≥ 0.485，W 的相对变化均值 ≥ 0.02，并且（池上收缩 LDA ≥ 0.54，或与 T 场 run 0–3 的 8–30 Hz CSP 前 4 个滤波器的子空间能量比初始化高 ≥ 0.05）。九人上的成功线是准确率均值比选定 C 的 0.416 高 ≥ 0.03，并且池探针或 CSP 子空间至少一条达到上面的水平。

每个准确率都带合格率和拒判数。前 20 步若单步中位时间超过 2 秒，或拒学超过一半，该候选记为 crash 并停掉，不改 β 再试。

## 不跑的

留出集。M17 的常数 100 倍前端学习率。在验证准确率上看完再改目标相对步长或 β。
