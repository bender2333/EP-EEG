# M17 预注册：前端为什么不动，以及 CSP 特征上的沙盘

写在任何 M17 运行之前。不改以前各阶段的预注册数字，不改 `eval/`，不读留出集。训练 run 0–3，验证 run 4–5。配对是 Wilcoxon 符号秩，双侧。本机 1 个 CPU。事后加的分析标探索性。

界：验证准确率差 ≥ 0.05 叫明显；绝对值 < 0.02 叫对齐。筛选只在被试 1、3、8、种子 0。最多提升 1 个候选到九人。种子 1、2 只在九人种子 0 比对照高 ≥ 0.03 时才跑。

## 块 1 前端矩阵为什么不动

测量，不是候选。臂 C、C_skip、C_nolake，初始化以及种子 0 的选定权重。被试 1、3、5、8。一批 32 个训练子窗，β=0.04，居中对比。

对每条通路，在结成共享权重之后、乘学习率之前的步上记：

- 相对步长：中位数 \|η·Δ\| / (|w|+1e-8)
- 相干：\|批内均值\| / 批内绝对值均值。≥ 0.5 叫相干，< 0.2 叫对消。

判定句，先写死：若前端相对步长 < 其他可学通路中位数的 0.2 倍，且相干 ≥ 0.5，结论是「步子小但方向一致」。若相干 < 0.2，结论是「批内对消」。两者可以同时不成立，那时写成「介于两者之间」。

唯一的训练候选 `front_rate`：把前端突触的 `synapse_rate` 乘一个常数。常数用 A01、臂 C、训练后权重、上面那一批训练子窗估出来，等于出水口相对步长的中位数除以前端相对步长的中位数，截断到 [1, 100]。不许看验证准确率来改这个数。

筛选：臂 C，被试 1、3、8，U=500，η=0.3。提升条件同时满足：三人 W 相对变化的均值 ≥ 0.02，且判决均值 ≥ 网格里 C 在 U=500 的这三人均值（0.455）加 0.03。提升后九人、种子 0、U=1500。不满足就不提升。和 CSP 的相似度只在提升之后才算，用 8–30 Hz 的 CSP 矩阵和训完的 W 的余弦，标成测量，不另开候选。

## 块 2 CSP 的 32 维特征

特征与 M16 块 2a 相同：8 带 × 4 个 CSP，只在 T 场 run 0–3 拟合，训练集标准化。对照是 M16 已有的九人种子 0：32 维 LDA 均值 0.675，平衡传播线性头 0.640。头不重训。

新网络最多 3 个，输入是这 32 维，没有子窗：

| 候选 | 结构 |
| --- | --- |
| pools | 32 个可平方的池神经元，与对应输入固定相连，池与 4 个奇出水口互惠 |
| lake | 每池 2 个微柱，微柱全连接，微柱与出水口互惠，没有跳连 |
| lake_skip | 同上，另加池与出水口互惠 |

η=0.3，β=0.04，温度 0.01，U=600。筛选被试 1、3、8。提升条件：三人均值比这三人的 M16 线性头高 ≥ 0.03，或与这三人的 32 维 LDA 差的绝对值 < 0.02。最多提升 1 个。提升后九人、种子 0；种子 1、2 只在种子 0 比九人线性头高 ≥ 0.03 时才跑。
