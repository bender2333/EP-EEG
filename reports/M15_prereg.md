# M15 预注册：平衡传播的学分派到哪里停下

写在任何 M15 运行之前。不改 `reports/M14.md` 的预注册数字，不改 `eval/`，不读留出集。训练只用 T 场 run 0–3，选参和评估只用 T 场 run 4–5。界和 M14 诊断一样，用验证准确率差 0.05；配对检验是九名被试准确率的 Wilcoxon 符号秩，双侧。种子 0 的已有权重做分解和对齐；只有下面点名的候选才用种子 1、2。事后加的分析标成探索性，不改这些句子。

合格率低于 0.98 的运行先记成收敛问题，不拿来解释学分。

## 块 1 读出分解

问题：C 的池、微柱、出水口线性探针都还在，奇出水口的 argmax 掉下去。掉的是判决规则，还是平衡传播连一个线性读出都拟合不了。

用种子 0、U 为各臂选定值的已有权重（C：η=0.3、U=3000；C_nolake：η=0.3、U=2000；C_skip：η=0.3、U=3000；A：η=1、U=3000）。九人。

| 编号 | 做法 | 事先的判定 |
| --- | --- | --- |
| H1 | 同一份试次平均的出水口状态上，收缩 LDA 对逻辑回归（反向传播的线性读出） | 两者验证准确率差的绝对值 < 0.02 算「一样」；都比奇判决高 ≥ 0.05 且 p < 0.05 则差距在判决规则 |
| H2 | 把出水口状态冻结成输入，用居中 ±β 的平衡传播再训一个线性头（试次向量，和 LDA 同一批特征） | 与 H1 的逻辑回归差 < 0.02：平衡传播拟合得了这条线性映射；低 ≥ 0.05 且 p < 0.05：学分在冻结特征上的线性读出就失败 |
| H3 | 同样比较池状态（C、C_nolake、C_skip）和微柱状态（C、C_skip、A） | 逻辑回归贴近 M14 探针的那一层；平衡传播头再低 ≥ 0.05 则学分停在「读已经有的状态」 |
| H4 | 出水口几何：正确类减次高类的裕度、\|s\|>0.8 的比例、跨试次标准差 < 1e-3 的出水口个数 | 只描述。均值裕度 < 0.05 或饱和比例 > 0.3 记成「奇出水口挤在一起或饱和」 |

块 1b，最多 4 个候选，只在被试 1、3、8、种子 0、U=1500 上筛选。和同一三人、同一 U 的 C（η=0.3，网格里已有）比。均值准确率高 ≥ 0.03 才提升到九人、U=3000、种子 0、1、2；最多提升 1 个。其余不提升。

| 候选 | 相对 C 的唯一改动 |
| --- | --- |
| beta_low | β=0.01，仍居中 |
| beta_high | β=0.2，仍居中 |
| one_sided | β=0.04，不居中（微扰相对自由相，没有 −β） |
| eta_out | 出水口通路的突触步长乘 5，其余不变 |

## 块 2 梯度对齐

在已有权重上，不重新训练。臂 C、C_skip、C_nolake、A。被试 1、3、5、8。每个臂两个时刻：初始化，和选定 U 的权重。

一条固定的训练子窗批（32 行）。平衡传播的更新方向取居中对比在结成共享权重之后、乘学习率之前的步。真梯度用自由相交叉熵（温度 0.01，和训练的 nudge 相同）对同一批参数的中心差分，步长 1e-3；前端抽 16 个共享组，其余每条通路抽 16 对互惠突触，整组一起扰动。

β 取 0.01、0.04、0.1，只改对比，不改权重。真梯度与 β 无关，只算一次。

余弦 > 0.7 记「对齐」，< 0.2 记「错位」，中间记「部分」。四人里至少三人通路排序一致，才说卡在哪一层。否则写成「因人而异」。

## 块 3 沙盘消融

只在块 2 满足下面这一条时才跑：在 C 或 C_skip 的训练后权重上，微柱侧向或微柱↔出水口的余弦是最低的，而且 < 0.2，同时另一条通路 > 0.5，四人里至少三人如此。否则本块不跑，记成「预注册的启动条件没满足」。

启动之后，最多 3 个候选，被试 1、3、8，种子 0，U=1500，底子是 C_skip：去掉微柱侧向；`skip` 预算改成 0.3；初始化行质量上限改成 0.95。和这三人的 C_skip 在 U=1500 比，高 ≥ 0.03 才记成值得加长，本阶段不再自动加到九人。

## 块 4 前端天花板

同一 T 场划分上的参照，种子 0，九人：

- FBCSP+LDA：仓库里组 4 的实现（`ep_eeg/baselines.fbcsp`），输入是冻结评估层的试次。
- 8 个 4 Hz 频带（4–36 Hz）× 22 导联的对数方差，收缩 LDA，不做共空间模式。
- 把这 176 维冻结特征送给平衡传播线性头。

判定：平衡传播头与对数方差 LDA 的验证准确率差 < 0.02，则平衡传播读得了这组特征，0.54 的天花板在原始时间窗的前端，不在学分。低 ≥ 0.05 且 p < 0.05，则更富的冻结前端上学分仍然失败。不在本预注册里把滤波器组再送进完整的 C_skip；若以后做，标探索性。
